# 🐤 꾹꾹이의 대모험 (Kkukkuki's Adventure)

주인공 **꾹꾹이**가 총을 쏘며 전진하는 가로 횡스크롤 액션 게임.
「슈퍼 마리오」의 블록 부수기 · 밟기와 「소닉」의 속도감을 섞었고,
초등 고학년이 즐길 수 있게 난이도와 연출을 맞췄다.

## 실행 방법

`kkukkuki/index.html` 을 브라우저에서 열면 끝. 설치·빌드·서버 전부 필요 없다.

```bash
# 그냥 더블클릭해도 되고, 로컬 서버로 열어도 된다
npx http-server kkukkuki -p 8080
```

## 조작

| 키 | 동작 |
|---|---|
| `←` `→` | 걷기 / 달리기 (계속 누르면 가속) |
| `Space` `Z` | 점프 — **길게 누르면 더 높이** |
| `X` `J` | 씨앗 총 발사 |
| `↑` + 발사 | 위쪽으로 발사 |
| `↓` | 웅크리기 / 통과 발판에서 `↓`+점프 = 아래로 내려가기 |
| `P` `Esc` | 일시정지 · `R` 스테이지 재시작 · `M` 음악 |

모바일·태블릿은 화면에 터치 버튼이 자동으로 나온다.

## 적

| 적 | 행동 | 공략 |
|---|---|---|
| 🐱 고양이 | 순찰하다 조준 후 사격 | 밟기 1방 / 총 1방 |
| 🐶 강아지 | 가까이 오면 **돌진**, 2연발 사격 | 체력 2 |
| 🐦 새 | 하늘을 날며 **폭탄 투하** | 폭발 범위 주의 |
| 🦍 고릴라 | 나무·빌딩 **위에서 드럼통을 던짐** | 체력 5, 옥상으로 올라가 처치 |
| 👑 킹 고릴라 | 스테이지 3 보스. 체력 절반 이하면 분노 → 드럼통 2개 + 착지 충격파 | 체력 16 |

**드럼통은 총으로 부술 수 없다.** 점프로 피하거나 *파워 샷* / *무적* 상태로 부숴야 한다.

## 아이템 (`?` 상자를 머리로 치거나 쏘면 열림)

| 아이템 | 효과 | 지속 |
|---|---|---|
| ⭐ 무적 | 닿는 적이 전부 사라짐 | 9초 |
| ⚡ 스피드 업 | 최고 속도 대폭 상승 | 10초 |
| 🕊 날개 | 공중에서 점프 유지 → 활공·상승 | 9초 |
| 🔫 파워 샷 | 3방향 산탄 + 2배 데미지, 드럼통도 파괴 | 11초 |
| ❤️ 하트 | 체력 1 회복 | 즉시 |

## 스테이지와 퀘스트

스테이지마다 퀘스트 3개가 있고, 달성한 만큼 **별(★)** 을 받는다.
클리어 기록·별·최고 점수는 브라우저에 저장된다.

1. **꾹꾹이 숲** — 열매 24개 / 적 8마리 / 120초 안에 도착
2. **꾹꾹이 시티** — 열매 30개 / 적 12마리 / 무피격 통과
3. **노을 폐허** — 열매 34개 / 보스 격파 / 170초 안에 도착

## 고수 팁

- 적을 밟는 순간 **점프를 누른 채로** 있으면 더 높이 튄다. 연속으로 밟으면 **콤보 배수**로 점수가 붙는다.
- 체크포인트(노란 깃발)를 지나면 죽어도 거기서 부활한다.
- 남은 시간 × 12 + 별 × 800 이 클리어 보너스라, 빠르게 깨는 게 이득.

## 파일 구조

```
kkukkuki/
├── index.html
├── css/style.css
├── js/
│   ├── core.js      상수 · 유틸 · 입력 · 사운드(WebAudio 합성)
│   ├── sprites.js   모든 캐릭터를 캔버스로 직접 그림 (이미지 파일 없음)
│   ├── levels.js    스테이지 ASCII 맵 + 퀘스트 정의
│   ├── world.js     타일맵 · 충돌 · 카메라 · 배경
│   ├── entities.js  꾹꾹이 · 적 · 드럼통 · 탄환 · 아이템
│   └── game.js      게임 루프 · 상태 전환 · HUD
└── tools/gen_levels.py   levels.js 생성기 (맵 정렬을 안전하게)
```

### 맵 수정하기

`js/levels.js` 의 `rows` 배열을 직접 고쳐도 되고,
`tools/gen_levels.py` 를 고친 뒤 `python3 tools/gen_levels.py` 로 다시 만들어도 된다.

```
.  빈 칸          P  꾹꾹이 시작      1  고양이
#  흙             G  골 깃발          2  강아지
=  돌 블록        K  체크포인트       3  새
-  통과 발판      C  열매(코인)       4  고릴라
B  부술 벽돌                          5  보스 고릴라
?  아이템 박스
T  나무 기둥(통과)  ^  나뭇잎(발판)
H  빌딩 벽        h  창문   p  기둥(통과)   S  가시
```
