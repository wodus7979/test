# Aged limestone facade

Original game material generated with the built-in `image_gen` tool on 2026-09-12. No existing game's texture was copied. Used on the retail and workshop exterior geometry by CityPackSetup. Actual output: 1254 × 1254 PNG; imported with mipmaps, repeat addressing and anisotropic filtering. Seamlessness was requested, but the image is not a measured photogrammetry/PBR scan.

Saved project asset: `SniperRidge/Assets/Resources/UrbanDetail/aged_limestone.png`.

Prompt:

Use case: photorealistic-natural. Asset type: square seamless repeating base-color texture for a Unity FPS building wall, NOT a building photograph. Create an original photorealistic aged grey limestone masonry surface, small irregular rectangular blocks in horizontal courses, weathered mortar, subtle moss in some seams, pores, chipped edges and restrained brown-grey variation. Square 2048x2048. Orthographic straight-on flush view, flat diffuse overcast lighting with NO directional cast shadows, NO highlights or vignette. All four edges must tile seamlessly, similar-sized stones across entire image, approx 3 metres of wall in view with 12 horizontal courses. Neutral medium grey, realistic fine detail. Full frame filled with stone masonry. No windows, doors, sky, frame, text, watermark, logos, or recognizable game imagery. This will be repeated on 3D geometry, not displayed as a scene.
