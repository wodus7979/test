# Olive Titan provenance

The anatomical base mesh, morph targets, rig definitions and low-poly eye geometry are CC0 assets from MakeHuman / MPFB. The original CC0 text and MPFB licensing explanation are included here.

- MPFB repository: https://github.com/makehumancommunity/mpfb2
- Source revision used: afb9f530a7c2741dedb8df0ebae2e0b183caec21
- Official system assets: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
- Archive used: https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip
- License information: https://static.makehumancommunity.org/about/license.html

The delivered mesh has custom proportions, anatomical surface changes, a derived clothing shell, a custom scalp mesh and procedural baked materials. The final texture atlas does not contain pixels copied from the user's image reference. The face was assembled from anatomical morphs rather than a scan or likeness of an actor or named character.

The intermediate base Blender file also contains the CC0 MakeHuman short01 hair used during setup; the final FBX uses the custom scalp shell instead.

Blender 4.5 and MPFB were build tools. Their executable/addon code is not bundled. The included build script imports an externally installed MPFB checkout. MakeHuman's license statement expressly treats exported assets and saved model files as user output. This provenance file does not assign a new license to the user's custom creative contribution.
