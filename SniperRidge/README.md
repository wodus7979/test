# Sniper Ridge (Unity 3D 저격 게임 테스트)

## 현재 업데이트: 오른쪽 아래 총 · 적 깃발 길찾기 · 석재 도시 (2026-09-12)

`codex/urban-fps`에서 받습니다. 아래 과거 업데이트의 화면/증원 설명보다 이 설명이 우선합니다.

- 총의 몸통과 손을 오른쪽 아래로 내리고 카메라에서 더 멀리 배치했습니다. 기관총/저격총/로켓포는 각 크기에 맞춰 조정합니다. 우클릭 조준 때만 중앙에 올리며 팔은 표시하지 않습니다. 재장전 손동작은 유지합니다.
- **공격 목표 안내:** 화면에 `적 깃발 F1 · 거리` 표식이 실제 목표를 따라 표시됩니다. 건물 뒤에서도 보이고, 화면 밖이면 방향 화살표가 나옵니다. 상단 나침반은 카메라 기준 방향을 표시합니다. 왼쪽 작은 지도에 전체 구역·동료·깃발이 보이며 **Tab을 누르는 동안 큰 전술 지도와 NavMesh 경로**가 표시됩니다. 깃발 6개를 E 2초로 차례로 탈취합니다. 아군 거점을 방어하거나 적을 모두 처치하는 조건은 없습니다.
- **전진할 여유:** 증원 후보는 적 깃발 주변 26~52m에서 무작위로 뽑되 현재 플레이어의 뒤쪽은 제외합니다. 14~20초마다 3~5명, 적 생존 상한 24명입니다. 사선도 없고 플레이어와 38m 이상 떨어진 이동 병사는 깃발 주변을 지킵니다. 깃발 탈취 후 다음 증원까지 12초를 주며 진행 중이던 이전 깃발 증원도 중단합니다. 기존 적은 계속 싸울 수 있습니다.
- **도시 표면:** 상가/정비소 외벽에 새 회색 석재 질감, 창문마다 커튼/블라인드/명암 변형, 추가 창살·일부 판자·실외기를 적용합니다. 건물별 외벽 색을 조금씩 바꾸고, 도시의 환경광/그림자를 중성 색으로 조정했습니다. 아스팔트의 밝은 자갈 잡음을 줄이고 도로 보수면·맨홀·배수구·종이 쓰레기를 추가했습니다. 긴 보도의 텍스처가 늘어나던 UV도 실제 길이에 맞췄습니다. 장식은 이동/총알 충돌체를 바꾸지 않습니다.
- **시야:** 화면 전체를 붉게 덮던 피격 효과를 가장자리로 제한하고 도시 FPS의 큰 로켓 버튼과 바람 화살표를 정리했습니다.

Unity를 닫고 저장소에서 `git pull --ff-only origin codex/urban-fps`, 다시 열어 도시 에셋 자동 재생성이 끝날 때까지 기다리세요. 도시 버전은 **`city-stone-streets-4`**입니다. 기존 모습이 남으면 **Sniper Ridge → 도시 에셋 생성**, 이후 **Play → 0번 도시 FPS → Enter**로 실행하세요.

검증: C# 구문·diff 검사와 기존 도시 충돌체 기반 경로 검사를 사용합니다. **이 Mac에는 Unity가 없어 컴파일, 실제 화면, 전투 난이도, 지도/재장전의 Play 검증은 하지 못했습니다.** 첨부된 Call of Duty 장면을 방향성으로 삼아 개선한 프로토타입이며 같은 완성도를 달성했다고 평가한 상태는 아닙니다.

목표 안내는 [Call of Duty 공식 HUD/나침반 설명](https://blog.activision.com/call-of-duty/2019-10/Getting-Started-in-Modern-Warfare-Controls-and-Settings-PC)을 참고했습니다. 원본 게임 에셋은 복사하지 않았습니다. 새 석재는 내장 이미지 생성 도구로 만들었으며 [질감 저장 위치와 생성 프롬프트](Assets/Resources/UrbanDetail/README.md)에 기록했습니다.

## 현재 도시 FPS: 깃발 탈취 · 동료 4명 · 양측 총격전 (2026-09-12)

**`codex/urban-fps` 브랜치**입니다. 이전의 구역별 100초 방어/정해진 증원 지점 방식을 교체했습니다. 아래의 과거 업데이트보다 이 설명이 우선합니다.

- **목표:** 도시의 깃발 6개를 순서대로 탈취합니다. 현재 깃발 3.2m 안에서 사선이 통할 때 **E를 2초 유지**하면 탈취하며, 손을 놓거나 벗어나면 그 조작 진행이 초기화됩니다. 적이 살아 있어도 다음 깃발로 전진할 수 있습니다. 모든 깃발을 탈취하면 승리합니다. 시간 버티기 조건은 없습니다.
- **동료 4명:** 기관총병 2명, 저격병 1명, 로켓병 1명이 함께 출발합니다. 청록색 군복과 파란 표식으로 구분하며 자동으로 따라오고 적을 골라 사격합니다. 플레이어와 멀어지면 합류합니다. 각자 체력 100이며 피격/폭발로 전사할 수 있고 해당 작전 중 부활하지 않습니다. 화면에 4명의 체력/전사를 표시합니다. 같은 팀의 사격으로는 피해를 주지 않습니다.
- **양측 교전:** 적도 플레이어와 동료 중 공격할 대상을 고릅니다. 실제 비행 탄환의 첫 충돌과 폭발 사선으로 피해를 판정하며, 살아 있는 병사 뒤의 병사에게 탄환이 관통하지 않습니다. 근접 탄환이나 피격에 반응해 엄폐를 찾고, 반격 후 다른 위치로 이동합니다. 로켓은 별도 발사체로 날아가 범위 피해를 줍니다.
- **방어와 증원:** 각 깃발에 모래주머니 기관총/저격 진지를 배치하고, 지지면과 사선이 확인되는 건물 옥상에도 저격병 또는 로켓병을 배치합니다. 이동 증원은 고정 좌표 대신 플레이어/목표 주변 26~52m에서 매번 후보를 뽑습니다. 시야·주변 병사와의 거리·충돌·경로를 검사한 뒤 4~6명이 나뉘어 등장하며, 증원 간격은 8~12초, 적 생존 상한은 24명입니다.
- **이동 변경:** 기존 도시 전술 코드를 제거하고 양팀 공용 `InfantryCombat`과 Unity `NavMeshAgent`로 교체했습니다. 엔진의 경로 추종/서로 피하기를 이용하며, 이동 경로를 설정하는 것과 실제 이동을 시작하는 것을 분리해 속도가 0으로 고착되지 않도록 했습니다. 정지 사격·엄폐·측면 이동을 함께 사용합니다.
- **플레이어 무기:** **1 돌격소총 / 2 기관총 / 3 저격총 / 4 로켓포**, Q는 로켓포/직전 주무기 전환입니다. 무기별 탄창과 예비탄을 보존하며 교체만으로 탄약이 늘지 않습니다. R 장전, G 수류탄, 우클릭 조준, WASD 이동, Shift 달리기, C/Ctrl 앉기, Space 점프, M BGM입니다.
- **양손과 재장전:** 양손을 손잡이와 총열 덮개에 배치했습니다. 화면을 가리던 FPS 팔/소매 메시를 제거하고 장갑 손목도 짧게 줄여 손만 보이도록 수정했습니다. 왼손으로 탄창/탄약 상자를 빼고 넣은 뒤 장전 손잡이를 당기며, 기관총 덮개와 저격총 노리쇠도 움직입니다. 로켓 재장전에는 손으로 새 탄을 넣는 동작을 사용합니다. 촬영 모션이 아닌 직접 구성한 절차적 동작입니다.

- **도시 분대 이동·사격 현황:** Play 중 양팀 발사 횟수·이동한 병사 수·NavMesh 연결 상태를 Console에 기록합니다. 시작 25초 후에도 한 번 자동 기록하며, 사격 기회가 누적됐지만 발사하지 않는 병사는 경고합니다. 이 Unity 검사들도 여기서는 실행하지 못했습니다.


## 도시 적 정지/사격 중단 보완 · 차량 메시 교체 (2026-09-12)

**`codex/urban-fps`** 브랜치입니다. 이전 전술 변경 후 적이 서 있고 공격하지 않는 제보에 따라, 공격을 막을 수 있는 상태 전환과 이동 처리를 보완했습니다.

- 지속 조준/근접 탄환이 위협 시간을 무한 연장하지 않도록 바꿨습니다. 위협 반응은 4초 간격으로 받고, 위협 지속 시간은 반응 지연 이후 1초로 제한합니다.
- 사선이 열리면 먼저 **3.5초 반격 상태**로 진입합니다. 회피 후 내다보기/측면 이동 중에도 사격할 수 있습니다. 기존 탄환 충돌·사선·사격 예고·공격 간격은 유지합니다.
- 이동하려는데 1.2초 이상 진전이 없으면 경로를 갱신하고, 사선이 있으면 반격, 없으면 다른 이동 위치를 선택합니다. NavMesh 이동은 실제 내비게이션 표면 높이에서 시작하고 경로의 꺾이는 지점을 지나면 다음 지점으로 진행합니다. 목표까지 남은 거리보다 크게 이동하지 않게 했습니다.
- **세단·화물 밴 새 3D 메시:** 곡면 차체, 바퀴가 들어가는 휠 아치, 둥근 타이어/트레드, 알로이 휠/스포크/볼트, 경사진 유리, 도어 틈/손잡이, 사이드미러, 와이퍼, 범퍼, 그릴, 전후등, 번호판을 구성했습니다. 각각 약 1.86만 삼각형이며 템플릿을 재사용합니다. 도색·유리·고무·금속 재질을 분리하고, 도로/적 이동 검증에 쓰는 차량 충돌체 크기는 유지합니다. 직접 만든 게임용 모델이며 실차 스캔 에셋은 아닙니다.

차량 원본은 `Assets/Resources/Vehicles/sedan.json`, `van.json`입니다. `Tools/build_urban_vehicles.py`로 재생성할 수 있으며 Unity 실행 시 메시를 구성합니다. Unity를 닫고 `git pull --ff-only origin codex/urban-fps` 후 다시 열어 **0번 도시 FPS**를 시작하세요.

검증: C# 94개 파일 구문, 차량의 면/법선 방향·삼각형·크기, 기존 도시의 목표/적 진입 경로를 검사했습니다. 깊이 버퍼를 사용하는 CPU 렌더로 차량 형상도 확인했습니다. **Unity 컴파일/Play와 실제 AI 동작은 이 Mac에 Unity가 없어 미실행입니다.** **Sniper Ridge → 도시 적 회피·엄폐 판단 검사**에는 실제 상태 코드와 NavMesh를 20초씩 진행시켜 이동, 연속 사격 기회, 지속 조준 중 반격, 엄폐 후 재공격을 확인하는 검사를 추가했습니다. 해당 Unity 검사 역시 여기서는 실행하지 못했습니다.

## 도시 보병의 회피·엄폐·재공격 (2026-09-12)

같은 **`codex/urban-fps`** 브랜치입니다. 도시 FPS의 이동 보병에 상황을 판단하는 전술 상태를 추가했습니다. 기존에는 플레이어 7m 앞에서 정지 사격을 반복했고, FPS에서는 근접 탄환에 반응하지 않았습니다.

- **위협 감지:** 피격, 몸에서 2.5m 이내를 통과한 탄환, 시야가 통하는 상태에서 플레이어가 약 0.45초 이상 자신을 겨냥하는 상황에 반응합니다. 추가 반응 지연은 0.25~0.55초이며 연속 사격이 그 지연을 계속 초기화하지 않습니다. 벽 너머 탄환은 근접 위협으로 처리하지 않고, 충돌한 탄환은 충돌점까지만 검사합니다.
- **실제 엄폐 선택:** 주변 2.5~13m에서 이동 가능한 위치를 찾습니다. 앉은 머리·몸통·양어깨를 건물/차량 같은 실제 장애물이 가리는지, 길이 연결되는지, 다른 적이 그 자리를 사용하려는지 확인합니다. 부상 시에는 플레이어에게서 더 먼 위치를 선호합니다.
- **전투 흐름:** 엄폐로 달리기 → 몸 낮추기 → 사선이 열리는 옆 위치로 이동 → 최대 약 2.1초 노출 사격 → 복귀 또는 다른 자리로 이동. 최대 두 차례 내다본 뒤 위치를 바꿉니다. 피하는 중에는 준비한 사격을 취소합니다. 엄폐나 사격 위치를 찾지 못하면 옆으로 이동하고 다시 접근하며, 경로를 못 따라갈 때도 정해진 시간이 지나면 재판단합니다.
- **뒤에서 오는 적:** 접근 중 플레이어와 사선이 열리면 엄폐/측면 이동을 선택합니다. 플레이어가 돌아서 조준하거나 사격하면 위협에 반응하므로 기존처럼 가까이 와서 정지 사격만 반복하지 않습니다. 시야를 잃으면 마지막으로 파악한 위치를 기준으로 이동합니다.

원본은 [CC0 Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library)입니다. 경기관총은 실제 AK-47 녹음을 게임용으로 사용하므로 외형과 녹음 총기의 모델은 다릅니다. 파일별 원본·추출 시점·가공 내용은 `Assets/Resources/Audio/SOURCES.md`와 `recorded_shots.json`에 있습니다. 로켓포·폭발·장전 등은 기존 효과음을 유지합니다.

적은 기존 스킨 3D 병사와 Animator에 다음 동작을 더했습니다. 새 모션캡처 파일이 아니라, 뼈와 양팔/다리 IK로 만드는 엄폐 동작입니다.

- **나무**: 체중 이동 → 바깥발을 들어 옆으로 디딤 → 뒤따르는 발 이동 → 어깨와 총을 내밀어 조준 → 역순으로 엄폐. 한 번에 한 발만 들며, 방향 전환은 완전히 숨은 뒤에 합니다.
- **바위**: 두 발을 앞뒤로 고정하고 깊이 웅크렸다가 무릎을 펴며 일어납니다. 상체를 세우고 총을 들어 사격한 뒤 다시 내려갑니다.
- 머리/상체의 시선, 호흡, 사격 반동과 양손 총기 지지를 함께 적용합니다. 전체 모델을 미는 방식 대신 각 관절이 움직입니다. 발을 디디고 조준 자세가 완성된 뒤에만 사격합니다.
- 머리·몸통·팔·다리 피격 판정은 최종 뼈를 따라갑니다. 내딛는 중 처치되면 당시 골반 이동 속도를 사망 물리에 전달합니다.

Unity를 다시 열면 **적 애니메이션 v5**로 자동 갱신합니다. 필요한 경우 **Sniper Ridge → 적 애니메이션 다시 생성**, **총성 오디오 다시 가져오기**를 실행하세요. **엄폐 동작·녹음 총성 검사** 메뉴는 발 지지/복귀/사격 시점과 오디오 가져오기 상태를 검사합니다.

검증: WAV 23개·연사 겹침, 기존 FBX 49개 뼈/1,800개 애니메이션 곡선, 전체 C# 문법을 검사했습니다. **이 PC에는 Unity가 없어 컴파일·Play·검사 메뉴·최종 동작 및 청음은 실행하지 못했습니다.** 다른 PC에서 저격총 4배로 나무 양쪽과 바위의 등장/복귀를 확인하고, 7종 총기의 단발/연사와 보이는 부위의 피격 판정을 확인하세요.

## 전술 작전실 시작 화면

시작 화면을 어두운 군용 색상의 작전 준비 화면으로 바꿨습니다. 왼쪽은 무기 7종 목록, 중앙은 선택한 무기의 실제 3D 에셋과 탄약/재장전 정보, 오른쪽은 해당 임무의 목표와 전술 개요입니다. 저격을 선택하면 적의 배치를, 방어전을 선택하면 적의 진입 방향을 표시합니다. 전술 개요는 실시간 레이더가 아닙니다.

- **클릭 또는 1~7**: 무기 선택. 선택만으로 임무가 시작되지 않습니다.
- **작전 시작 버튼 또는 Enter**: 선택한 무기로 출전합니다.
- 로켓포(Q)·수류탄(W)의 기본 지급 정보와 엄폐/이동/조준 조작을 출전 전에 확인할 수 있습니다.
- 화면 비율에 맞춰 전체 메뉴를 비례 축소/확대합니다. 무기 미리보기는 선택할 때만 렌더링하며, 출전 시 미리보기용 카메라·조명·렌더 텍스처를 정리합니다.
- 시작 화면에는 [Google Fonts의 나눔고딕](https://github.com/google/fonts/tree/main/ofl/nanumgothic) Regular/Bold 원본을 포함했습니다. 글꼴과 SIL Open Font License는 `Assets/Resources/UI/Fonts`에 있습니다.

검증: 전체 C# 문법과 주요 문구의 글꼴 폭, 메뉴 배치 수식을 확인했습니다. **작성 PC에 Unity가 없어 컴파일·Play·실제 GPU 미리보기는 실행하지 못했습니다.** 다른 PC에서 ① 무기 7종 모델 전환 ② 무기 클릭→다른 번호 키→Enter로 마지막 선택 무기가 시작되는지 ③ 저격/방어 임무 설명 ④ 16:9·16:10·울트라와이드에서 글자와 버튼 ⑤ 임무 종료 후 선택 화면 복귀를 확인하세요.

## 평지 전장과 가까운 적 배치

플레이어 고지대·맞은편 능선·계곡을 제거하고 전장을 같은 높이의 평지로 바꿨습니다. 플레이어 참호만 지면 아래로 파여 있으며, C/Ctrl 엄폐와 A/D 이동은 그대로 사용할 수 있습니다.

- 저격 임무 적 10명을 약 **45~105m**로 당기고 서로 다른 방향에 배치했습니다. 바위/나무 엄폐형과 순찰형은 유지합니다.
- 방어전은 약 **55~95m**에서 적이 나타나 접근합니다. 기존 웨이브와 반격 규칙은 유지합니다.
- 전방의 무작위 나무·바위·덤불을 비우고 풀 높이와 밀도를 낮췄습니다. 숲은 전장 양옆과 배경에 배치합니다.
- 저격소총은 **4/8/16배, 기본 4배**, 지정사수 소총도 기본 4배입니다. 두 총의 기본 영점은 **100m**, 조절 범위는 **50~600m**입니다.
- 이전 로켓포(Q), 수류탄(W), 적 반격과 관절 물리 사망 동작도 포함합니다.

Play를 다시 시작하면 새 전장이 자동 생성됩니다. Play 중 **Sniper Ridge → 평지 전투 배치 검사 (Play 중)** 메뉴로 참호 밖 평탄도, 플레이어 높이, 지형에 가려지지 않는 사선, 적 배치 거리와 기본 조준 설정을 검사할 수 있습니다.

작성 PC에서는 전체 C# 문법과 배치 거리 계산을 확인했습니다. **Unity가 없어 컴파일·Play 및 위 검사 메뉴는 실행하지 못했습니다.** 다른 PC에서 적이 잘 보이는지와 참호에서 일어서기/숨기, 적 반격을 확인하세요.

## 수류탄: W로 위치 지정 후 투척

사용자 제공 `grenade_asset_pack`의 올리브색 수류탄을 사용합니다. 메시·PBR 텍스처·수정된 Unity 빌더가 저장소에 포함되어 있으므로 다른 PC에서 다운로드 폴더를 따로 복사할 필요가 없습니다.

1. 일어선 상태에서 **W를 누르고 유지**하면 총을 내리고 수류탄을 듭니다.
2. **마우스**로 50m 안쪽의 지면/물체를 겨누세요. 곡선은 예상 비행·튕김 경로, 원은 **던진 뒤 3.2초 시점의 예상 폭발 위치**입니다. 가까운 폭발은 주황색으로 표시됩니다.
3. 원하는 위치를 확인한 뒤 **W를 놓으면 투척**합니다. 날아가는 동안 벽·바닥에 튕기며, 3.2초 뒤 폭발합니다. 타이머는 손에서 놓을 때 시작합니다.
4. **우클릭/Esc**로 취소할 수 있습니다. 엄폐하거나 창 포커스를 잃거나 임무가 끝나도 취소됩니다. 취소/잘못된 목표/손 앞 장애물은 수량을 차감하지 않습니다.

- 저격/방어 임무 모두 **6개** 지급, 방어전 웨이브 사이 **2개 보충(최대 6개)**. Q 무기 교체로 수류탄이 다시 채워지지 않습니다.
- 투척 간격 1초, 투척 직후 총 복귀 0.4초. 수류탄 조준 중 사격·조준경·재장전·로켓포 전환을 막습니다. 재장전/교체가 끝난 뒤 W를 눌러야 합니다.
- 수류탄도 저격 임무에서는 던질 때 위치가 드러납니다. 폭발 최대 피해 180, 반경 7m, 중심 2m에서 가장 강하며 거리에 따라 감소합니다. 지형/엄폐물이 폭발 피해를 막습니다. 가까이 있으면 플레이어도 다칠 수 있습니다.
- 폭발·피해·처치/X 표시와 소리는 로켓포의 공통 폭발 처리를 사용하고, 투척용 짧은 합성 효과음을 추가했습니다.
- 미리보기와 실제 비행은 같은 0.02초 간격 계산을 사용합니다. 원은 **예상** 위치이므로 던진 뒤 적이나 장애물이 움직이면 실제 위치가 달라질 수 있습니다. 수류탄끼리 및 시체와는 충돌하지 않습니다.
- 외형 에셋은 정적 모델입니다. 손가락/안전핀 분리 애니메이션은 포함하지 않습니다.

프로젝트를 열거나 Play/빌드 전 수류탄 프리팹을 자동 생성합니다. 수동 메뉴는 **Sniper Ridge → 수류탄 프리팹 생성 (Grenade Asset Pack)** 입니다.

검증: `python3 Tools/validate_grenade_assets.py`(numpy/Pillow 필요)에서 LOD 3,936/1,848개 삼각형, 법선·UV·Z축 변환·텍스처·기준점과 2–50m 탄도 수식을 확인했습니다. 전체 C# 문법 검사도 통과했습니다. **이 PC에는 Unity가 없어 C# 컴파일·Play·충돌 검사 메뉴·실제 화면/소리 검사는 수행하지 못했습니다.**

다른 PC에서 Play를 중지한 뒤 **Sniper Ridge → 수류탄 궤적·충돌 검사** 메뉴를 실행할 수 있습니다. 지면/벽 충돌, 사거리 제한, 30/60/144 FPS에서 미리보기와 비행 계산 일치, 시체 레이어 제외, 손 앞 장애물을 검사합니다. 실제 Play에서는 W 조준→놓기, 우클릭/Esc 취소, 잔여 수량, Q로 총/로켓포를 바꾼 뒤 투척, 엄폐 시 취소, 폭발 피해와 웨이브 보급을 확인하세요.

## 적 사망 동작: 관절 물리

사망한 병사 전체를 옆으로 회전시키던 방식 대신 **15개 신체 부위 / 14개 관절**의 물리 동작을 사용합니다. 머리·흉부·골반·팔·다리·손·발이 현재 애니메이션 자세에서 중력과 충돌에 반응합니다.

- 달리던 속도의 일부와 맞은 방향을 반영합니다. 머리 명중은 머리, 몸통 명중은 흉부에 작은 반응을 주고, 과도하게 튀지 않도록 관절 각도·각속도·밀려 나오는 속도를 제한합니다.
- 무릎과 팔꿈치가 접히고 지면·바위·참호와 충돌합니다. 소총은 손에서 떨어져 별도로 굴러갑니다.
- 원본 FBX의 스케일에 영향을 받지 않는 별도 물리 몸체가 렌더링 뼈를 따라 움직이게 합니다. 사망 순간에는 Animator와 살아 있는 적의 피격 콜라이더를 끕니다.
- 시체와 떨어진 소총은 Unity 기본 Ignore Raycast 레이어를 사용합니다. 총알·로켓·적의 시야·거리 측정은 이 레이어를 제외하므로 처치한 적의 새 물리 콜라이더가 다음 표적의 명중 판정을 막지 않습니다. 지형과의 물리 충돌은 유지합니다.
- 몸과 소총이 충분히 멈추면 물리 몸체를 고정합니다. 공중에서 타이머만으로 멈추지 않습니다. 방어전 시체는 기존처럼 25초 뒤 정리됩니다.

프로젝트를 열면 병사 애니메이션 설정 버전 5로 자동 갱신합니다. 수동 메뉴는 **Sniper Ridge → 적 애니메이션 다시 생성**입니다.

**다른 PC 확인**: 저격과 방어전에서 달리는 적, 웅크린 적, 바위 가까이 있는 적을 처치해 팔다리와 소총이 따로 움직이는지 확인하세요. Play 중 **Sniper Ridge → 적 쓰러짐 물리 검사 (Play 중)** 메뉴는 임무와 분리된 물리 씬에서 정지·달리기·웅크리기·12도 경사면, 1.5/2배 병사 크기를 각각 8초씩 시뮬레이션하고 관절 연결·지면 관통·소총 분리·사격 레이어를 검사합니다. 검사가 끝나면 임시 씬을 제거합니다.

작성한 PC에서는 FBX의 49개 뼈/1,800개 애니메이션 곡선 검사와 전체 C# 문법 검사가 통과했습니다. **Unity 컴파일·물리 검사 메뉴·실제 Play 화면은 이 PC에 Unity가 없어 실행하지 못했습니다.** 관절의 움직임과 경사면 접지는 다른 PC의 Play에서 최종 확인해야 합니다.

개발 참고: 격리된 물리 씬의 수동 진행에는 Unity 2022.3 [PhysicsScene.Simulate](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/PhysicsScene.Simulate.html)를 사용합니다. 실행 중인 임무의 기본 물리 씬은 검사에서 진행하지 않습니다.

## 로켓포 전환 (PC)

다운로드 폴더에서 가져온 `launcher_asset_pack`의 **재사용형** 모델을 보조 무기로 사용합니다. 저격/방어 임무 모두 처음 선택한 총과 로켓포를 함께 지급합니다.

- **Q**: 로켓포 ↔ 원래 총. 우상단 버튼은 **Esc**로 마우스를 풀고 클릭할 수 있습니다. 선택하면 시점 조작으로 돌아갑니다.
- **좌클릭** 발사, **우클릭** 2배 조준, **R** 재장전. **C/Ctrl** 엄폐 중에는 발사되지 않습니다.
- 장전 1발 + 예비 8발, 재장전 3.2초, 교체 0.6초. 교체 도중 발사할 수 없습니다.
- 탄약·배율·영점·발사 대기시간은 무기별로 보존합니다. 재장전 중 교체하면 미완료 재장전은 취소되며, 다시 R을 눌러 처음부터 장전합니다.
- 방어전 웨이브 사이에 주무기 예비탄 40%와 로켓 예비탄 2발을 각각 상한까지 보급합니다. 들고 있는 무기와 관계없이 해당 탄약에 적용됩니다.
- 로켓은 조준점 방향으로 초속 150m로 직진하는 게임용 투사체입니다. 탄두·연기 궤적·폭발 섬광·먼지·사운드가 있습니다. 지형과 엄폐물에 충돌하고, 중심 2m 최대 피해 220에서 7m까지 감소합니다. 벽은 폭발 피해를 막으며 한 적의 여러 신체 콜라이더는 피해를 중복시키지 않습니다.
- 저격 임무에서 로켓은 **발사 즉시 위치 발각**입니다. 가까운 폭발은 플레이어도 다치게 할 수 있습니다.

Unity를 열면 `Assets/Resources/Launchers`에 프리팹 3종을 자동 생성합니다. PC 1인칭 모델은 LOD0을 사용합니다. 수동 생성 메뉴는 **Sniper Ridge → 로켓포 프리팹 생성 (Launcher Asset Pack)** 입니다. 원본 Source JSON/PBR 텍스처와 수정한 빌더는 `Assets/LauncherAssetPack`에 포함되어 있어 다른 PC에서 에셋을 따로 복사할 필요가 없습니다. 생성된 파일은 Git에서 제외하고 빌드 전에도 누락 여부를 확인합니다.

검증: `python3 Tools/validate_launchers.py`(numpy/Pillow 필요)는 원본 메시·법선·좌표 변환·UV·텍스처 및 PCM 음원을 검사합니다. Unity의 **Sniper Ridge → 로켓포 에셋·탄약·폭발 검사** 메뉴는 프리팹/셰이더, 7개 주무기의 탄약 보존/재보급, 중복 피해/엄폐/폭발 반경을 검사합니다. 이 변경을 작성한 PC에는 Unity가 없어 **Unity 컴파일·메뉴 검사·Play/화면/청음은 아직 실행하지 않았습니다**. Python 검사와 전체 C# 문법 검사는 통과했습니다.

다른 PC의 Play 확인 순서:
1. 저격 임무에서 한 발 쏜 뒤 Q로 로켓포를 꺼내고, 다시 Q를 눌러 원래 총의 탄수가 유지되는지 확인합니다.
2. 로켓을 발사하고 R로 재장전합니다. 재장전 중 Q로 바꿨다가 돌아왔을 때 탄약이 생기지 않는지 확인합니다.
3. 적/지면을 향해 로켓을 발사해 궤적, 폭발, 처치/X 표시를 확인합니다. 벽 뒤의 적은 폭발 피해를 받지 않아야 합니다.
4. C/Ctrl로 숨은 상태에서 발사가 차단되는지, 방어전에서 로켓을 든 채 웨이브를 끝내도 총알/로켓이 따로 보급되는지 확인합니다.
5. Esc → 우상단 교체 버튼 → 좌클릭 발사가 자연스럽게 동작하는지 확인합니다.


평지 참호에서 가까운 전방의 적을 저격하거나, 몰려오는 적을 막는 1인칭 3D 게임입니다.
저장소에 포함된 에셋과 스크립트로 지형·적·UI를 생성합니다. 처음 열 때 에셋 자동 생성이 끝난 후 **Play** 버튼을 누르세요.

프로젝트를 열면 `Assets/FirearmAssetPack/Source` 의 메시 데이터에서 `Assets/Resources/Weapons/Prefabs` 프리팹이 자동 생성되고
(메뉴 **Sniper Ridge → 총기 프리팹 생성**), 1인칭 무기와 적 병사의 소총에 사용됩니다.

- 자동화기는 좌클릭(모바일은 사격 버튼)을 **누르고 있으면** 연사됩니다. 반동으로 조준점이 올라가고, 조준(우클릭) 시 산포가 줄어듭니다.
- 적 체력은 100입니다. 저격소총은 몸통 한 발, 지정사수 소총은 몸통 두 발, 돌격소총·경기관총은 몸통 2~3발, 헤드샷은 모든 무기 한 발입니다.
- **저격 임무**: 바위 엄폐형 4명, 나무 엄폐형 4명, 순찰형 2명. 빗나가거나 한 발에 처치하지 못하면 위치가 발각되어 반격합니다. 연속 5초 동안 엄폐해 시야에서 벗어나면 추적이 풀립니다. 적은 2배 크기, 거리 약 45~105 m.
- **방어전**: 웨이브마다 10 / 14 / 18 / 22 / 26명이 약 55~95 m 앞 평지에서 나타나 지그재그로 이동하며 사격하고 중간중간 멈춰 더 정확히 쏩니다. 10 m 앞에서 멈춰 계속 쏘므로 접근 전에 처리해야 합니다. 웨이브 사이 8초 휴식. 마지막 피격 후 3초가 지나면 엄폐 중 체력이 회복됩니다.
- 점수: 몸통 100, 헤드샷 250, 저격 임무는 거리 보너스(거리 × 0.5), 방어전은 웨이브 클리어 보너스.
- 방어전은 웨이브를 격퇴할 때마다 예비 탄약의 40%를 재보급받습니다 (최대 보유량까지).

## PC 그래픽 개선 (2026-09)

PC 기준으로 자연 팩을 실제 게임에 연결했습니다. **Unity 2022.3.62f3에서 컴파일·실행·화면·성능 확인은 아직 수행하지 않았습니다.** 아래 수치는 설정값이며 성능 측정 결과가 아닙니다.

- 일반 나무 4종·관목·장식 바위 2종을 `nature_fps_asset_pack` 모델로 교체합니다. 나무껍질과 바위는 팩의 알베도·노멀·금속/매끄러움 텍스처를 사용합니다. 잎은 양면 조명과 작은 바람 움직임을 추가했습니다.
- 화면에서 차지하는 크기에 따라 상세 모델 → 팩의 저해상도 모델 → 기존 간단한 모델로 전환합니다. 조준경을 확대하면 상세 모델이 다시 선택됩니다. 반복 메시·재질은 공유하고 GPU 인스턴싱을 활성화합니다.
- 사수 주변에는 짧은 풀·억새 모델을 최대 420회 배치 시도합니다. 중앙 사격 공간과 급경사는 제외하므로 실제 개수는 더 적습니다.
- PC 지형 높이맵은 257 → 1025, 재질 혼합맵은 256 → 1024입니다. 그림자 거리는 260 → 460m입니다. 첫 지형 생성 시간과 GPU 부담은 증가할 수 있습니다.

## 엄폐와 적 반격 (2026-09)

`codex/enemy-counterfire`에는 이전 그래픽·적 애니메이션·총성 타격감 변경이 모두 포함됩니다.

### 전투 흐름

- **저격전:** 한 발로 처치하면 은폐가 유지됩니다. 빗나가거나 부상만 입히면 사격 위치가 발각됩니다. 미스는 탄이 지형/엄폐물에 맞거나 수명(최대 6초)이 끝날 때 판정하므로 먼 허공으로 쏘면 경고가 늦을 수 있습니다. 적은 마지막으로 확인한 위치를 조준합니다. 5초 연속 엄폐해 적의 시야에서 벗어나면 다시 사격 기회를 얻습니다. 도중에 일어서거나 또 실패한 탄이 도착하면 엄폐 시간이 초기화됩니다.
- **방어전:** 적은 처음부터 진지 위치를 압니다. 접근 중에는 넓게 흩뿌리고, 멈추면 더 정확히 조준합니다. 숨어도 접근은 계속하므로 일어나 반격해야 합니다. 원래의 5개 웨이브와 탄약 재보급은 유지합니다.
- **회피:** C/Ctrl을 누르면 몸을 낮추고 조준경을 해제합니다. A/D로 좌우를 피할 수 있습니다. 숨거나 자세를 전환하는 동안 사격은 잠기며, 일어선 뒤 다시 쏠 수 있습니다. R 재장전은 엄폐 중에도 가능합니다. 체력은 마지막 피격 후 저격전 5초 / 방어전 3초가 지난 뒤 엄폐 중에만 회복합니다.
- **예고와 탄:** 화면에 적 방향과 조준/탄 접근 경고가 뜹니다. 적은 저격전 0.8초 / 방어전 0.5초 조준한 뒤 발사합니다. 조준 시작 때 정한 탄착점을 유지하며 숨은 눈 위치를 쫓지 않습니다. 탄은 주황 예광선으로 이동하고, 실제 도착 시점의 플레이어 위치와 엄폐물 충돌 순서로 피해를 판정합니다. 공중에서 명중을 미리 추첨하지 않습니다.
- **게임 속도:** 적탄의 목표 지점 도달 시간을 0.45~1.1초로 조정했습니다. 실제 탄속 재현이 아니라 보고 피하는 플레이를 위한 설정입니다. 이동·엄폐 속도와 적 정확도는 실제 플레이 후 조정할 수 있습니다.
- **엄폐물:** 사수 눈높이는 1.65m, 숨었을 때 0.58m입니다. 진지 앞의 모래주머니와 안쪽 흙벽(1.16m), 좌우 짧은 벽이 실제 탄을 막습니다. 숨기 자체가 무적 상태는 아닙니다. 벽을 우회해 몸에 도달하는 탄은 피해를 줍니다. 이미 날아온 탄은 추적 해제 후에도 소멸할 때까지 남습니다.

## 저격 명중 판정 수정 (2026-09)

`codex/sniper-hit-fix`는 기존 엄폐·적 반격·총성 개선을 포함합니다. 저격총으로 쐈는데 X 표시가 나오지 않는 문제를 조사하면서 두 가지 코드 문제를 수정했습니다. 사용자 PC에서의 정확한 실패 장면은 아직 재현하지 못했습니다.

- 플레이어 탄을 `Bullet.cs`로 분리하고 `LateUpdate` 실행 순서 300으로 이동했습니다. 병사 뼈와 명중 콜라이더는 `EnemyAnimationRig`의 순서 150에서 갱신되므로, 그 뒤 최신 위치로 충돌을 검사합니다. 물리 엔진의 자동 동기화 설정과 관계없이 첫 탄 검사 전에 프레임당 한 번 `Physics.SyncTransforms`를 호출합니다.
- 머리 뼈 원점에 있던 반지름 0.16m 구형 판정을 머리 위쪽으로 0.12m 연장한 캡슐로 바꿨습니다(병사 배율 적용 전 수치). 애니메이션 중에도 머리 방향을 따라갑니다. 상단 머리/헬멧 부근의 판정을 보완하며, 엄폐물을 관통시키지는 않습니다.
- 사격 결과를 따로 표시합니다: **처치 확인 / 명중·적 생존 / 지형·엄폐물에 맞음 / 가까운 엄폐물에 막힘**. 탄이 수명 안에 아무것도 맞히지 않으면 미명중 안내를 표시합니다.
- 저격총 피해량 100, 적 체력 100, 영점·바람·탄 낙하는 유지합니다. X 표시가 없으면 명중으로 처리되지 않은 것입니다. 바위나 나무에 가려진 부분을 쏘거나 바람·영점 때문에 빗나가면 여전히 피해가 들어가지 않습니다.

받은 뒤 Unity에서 저격 임무를 시작하고 **Sniper Ridge → 저격 머리 명중 검사 (Play 중)**를 실행하세요. 살아 있는 병사들의 머리 위쪽이 실제 물리 레이에 검출되는지 확인합니다. 이어서 몸통/머리 사격, 나무·바위 밖으로 나오는 적, 순찰 중인 적을 확인하세요. 새 프리팹을 수동으로 만들 필요는 없습니다.

이 환경에서는 C# 구문 검사와 코드 검토를 수행했습니다. Unity 컴파일, 위 검사 메뉴 실행, 실제 게임에서의 재현 확인은 아직 수행하지 못했습니다.


## 굴착 참호 (2026-09)

`codex/dugout-trench`는 저격 명중 판정·적 반격·총성 변경을 포함합니다. 사수 진지를 실제 지형 아래로 파인 참호로 구성했습니다.

- 지형 높이맵을 국소적으로 낮춥니다. 사격 발판은 기존 지표보다 0.90m 아래, 뒤쪽 통로는 발판보다 0.55m 더 낮습니다. 참호 경계는 원래 지형으로 부드럽게 연결하고 흙 재질로 칠합니다.
- 약 4.6m 폭의 사격 공간과 뒤로 이어지는 좁은 통로가 있습니다. 흙을 받치는 목재 벽, 수직 지지대와 철제 띠, 앞·옆 모래주머니, 흙 둔덕, 바닥 널판, 단차와 후방 계단, 배수로·보급 상자·탄피를 배치합니다.
- 모래주머니는 눌린 주름과 봉제선을 가진 공유 메시이며, 천의 짜임과 목재 결 텍스처를 생성합니다. 흙에는 기존 알베도/노멀 텍스처를 사용합니다. 별도 에셋 구매나 다운로드는 필요 없습니다.
- 참호 내부의 지형 잔디를 지우고 자연 팩 풀도 배치에서 제외합니다. 생성한 메시·재질·텍스처는 장면 종료 시 해제합니다.
- C/Ctrl 엄폐, A/D 좌우 회피, 재장전과 반격은 사격 발판에서 작동합니다. 후방 통로는 현재 공간 표현이며 W/S로 자유롭게 걸어 다니는 기능은 추가하지 않았습니다. 아래를 내려다보는 범위를 70도로 늘려 발판과 내부를 볼 수 있습니다.
- 플레이어의 서기/숨기 높이는 발판 기준 1.65m / 0.58m입니다. 벽의 흙 받침과 모래주머니 메시가 적탄을 막습니다. 참호 지표에 맞춰 플레이어의 절대 위치가 낮아졌으므로, 실제 임무에서 경사진 사선과 가시성은 확인해야 합니다.
