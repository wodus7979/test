# 황산벌 전투 역사 퀴즈

초등학생이 풀 수 있는 **황산벌 전투(660년)** 객관식 퀴즈입니다.
두 가지 버전이 있습니다.

| 파일 | 설명 |
| --- | --- |
| `hwangsanbeol_quiz.html` | 브라우저에서 클릭으로 푸는 그림 퀴즈 |
| `hwangsanbeol_quiz.py` | 터미널에서 푸는 파이썬 CLI 퀴즈 |

## 실행 방법

**HTML 버전** — 파일을 더블클릭하면 브라우저에서 바로 열립니다. 설치할 것이 없습니다.

**파이썬 버전**

```bash
python3 hwangsanbeol_quiz.py
```

파이썬 3만 있으면 되고, 따로 설치할 라이브러리는 없습니다.

## HTML 버전 화면

- **머리말**: 황산벌 들판 그림 — 왼쪽에 백제의 금빛 깃발 5개, 오른쪽에 신라의 푸른 깃발 20개로 병력 차이를 한눈에 보여 줍니다.
- **진격도**: 문제를 풀 때마다 깃발이 들판을 가로질러 앞으로 나갑니다.
- **문제 카드**: 문제마다 화면이 통째로 달라집니다. 12문제가 저마다 다른 삽화와 색을 가집니다.
  - 삽화 — 마주 선 두 진영, 계백 장군과 다섯 깃발, 창이 늘어선 신라 대군, 비어 있는 연도 두루마리,
    5 대 50 동그라미 비교, 들판의 이정표, 홀로 달려가는 화랑, 바다 건너 맺은 동맹,
    체크 넷과 가위표 하나가 그려진 방패, 한쪽으로 기운 저울, 해가 지는 성벽, 붓과 낙관
  - 색 — 문제마다 고유한 색상을 가지며, 카드 윗줄·진격 깃발·보기 번호·힌트 띠가 모두 그 색을 따릅니다
    (정답·오답 표시는 늘 초록·빨강으로 고정되어 헷갈리지 않습니다)
  - 갈래 — 문제 위에 인물 / 나라 / 숫자 / 땅 / 연도 / 사건 / 낱말 표시가 붙습니다
- **결과 화면**: 점수 원형 게이지, 계급(새내기 병사 ~ 삼국시대 박사), 오답 노트,
  병력 비교 그래프(동그라미 1개 = 군사 1,000명), 660년 사건 흐름 타임라인.
- 밝은 화면과 어두운 화면(다크 모드)을 모두 지원하고, 휴대폰 화면에도 맞춰집니다.

## 퀴즈 특징

- 총 12문제, 4지선다 객관식
- 문제 순서와 보기 순서가 매번 섞여서 나옴
- 답을 모를 때 `h`를 입력하면 힌트를 볼 수 있음
- 문제를 풀 때마다 쉬운 말로 된 해설이 나옴
- 마지막에 점수, 칭찬 메시지, 오답 노트를 보여 줌

## 화면 예시

```
[1/12번 문제] 황산벌 전투에서 백제 군사를 이끈 장군은 누구일까요?
  1. 김유신
  2. 계백
  3. 강감찬
  4. 을지문덕
정답 번호를 입력하세요 (힌트는 h): 2
⭕ 정답이에요! 잘했어요!
📖 백제의 계백 장군이 결사대를 이끌고 싸웠어요.
```

## 다루는 역사 내용

- 660년, 백제와 신라가 황산벌(지금의 충청남도 논산)에서 벌인 전투
- 백제 계백 장군의 결사대 5천 명 vs 신라 김유신 장군의 군사 5만 명
- 신라의 어린 화랑 관창의 용맹한 이야기
- 나당 연합군과 백제의 멸망

## 문제 추가하기

두 파일 모두 `QUESTIONS` 목록에 아래 형식으로 추가하면 됩니다.

```python
{
    "question": "문제 내용",
    "choices": ["보기1", "보기2", "보기3", "보기4"],
    "answer": "정답 보기",
    "hint": "힌트 문장",
    "explain": "해설 문장",
}
```

HTML 버전은 항목이 셋 더 있습니다.

- `scene` — 삽화 이름. `SCENES` 안의 `clash`, `gyebaek`, `yushin`, `year`, `troops`, `land`,
  `hwarang`, `allies`, `fourwins`, `outcome`, `fortress`, `word` 중에서 고르거나 새로 그려 넣습니다.
- `hue`, `sat` — 그 문제의 색(0~360의 색상값과 채도 %). 밝기는 화면 테마가 알아서 정하므로
  밝은 화면과 어두운 화면 모두에서 잘 보입니다.
- `tag` — 문제 갈래 (인물, 나라, 숫자, 땅, 연도, 사건, 낱말).

## 여행 발자국 지도

사진의 GPS를 읽어 다녀온 국내 시·군·구를 지도에 기록합니다. 서울은 집계에서 제외합니다.

### 폰만으로 (권장)

PC 도 앱 설치도 필요 없습니다. 지도 페이지를 폰 브라우저(Chrome)로 열고:

1. **내 파일** 앱을 열고 **내장 저장공간** 을 누릅니다
2. `DCIM › Camera` 폴더로 들어갑니다
3. 사진을 길게 눌러 고른 뒤 **더보기(⋮) › 압축**
4. 지도 페이지의 **사진 넣기** 를 눌러 만들어진 ZIP 을 고릅니다

**압축 메뉴가 안 보인다면** 홈 화면의 `이미지` · `동영상` 같은 분류 화면에서 고른 것입니다.
삼성 내 파일은 그 화면에서 더보기 메뉴를 축약해 압축을 넣지 않습니다. 반드시
`내장 저장공간` 을 눌러 실제 폴더로 들어간 뒤 고르세요.

**갤러리에서 바로 고르면 안 됩니다.** 안드로이드가 사진을 앱에 넘길 때 위치를 지우기
때문입니다. ZIP 은 사진이 아니라 일반 파일이라 폰이 손대지 않아 위치가 그대로 들어옵니다.

사진이 많으면 몇 번에 나눠 압축해도 됩니다 — 기록은 브라우저에 계속 누적됩니다.
2,000 장(115MB) ZIP 을 약 6 초에 처리합니다. 항목의 앞부분만 읽으므로 큰 ZIP 도
메모리에 통째로 올리지 않습니다.

지도에서 지역을 탭하면 지역명과 사진 수, 방문 시기가 나옵니다.

### 1. 브라우저에서 (준비 없이)

`travel_map.html` 을 브라우저로 열고 사진을 끌어다 놓거나 `파일에서 고르기`로 고릅니다.

**안드로이드에서는 브라우저로 기존 사진의 위치를 읽을 수 없습니다.** 안드로이드는
갤러리에 있는 사진을 앱에 넘길 때 EXIF 위치를 지웁니다. 앨범으로 고르든 파일 탐색으로
고르든 결과가 같습니다. 그 자리에서 카메라로 새로 찍은 사진만 위치가 남는데, 이건
갤러리를 거치지 않고 곧바로 전달되기 때문입니다. 브라우저 안에서 우회할 방법이 없으므로
**해결책: 사진을 ZIP 으로 압축해서 넣으세요.** 압축 파일은 미디어가 아니라 일반 파일이라
안드로이드가 내용을 건드리지 않으므로 EXIF 위치가 그대로 살아 있습니다. 폰의 파일 관리자
앱에서 `DCIM › Camera` 의 사진을 골라 압축한 뒤 그 ZIP 하나를 넣으면 됩니다. 앱 설치도
PC 도 필요 없습니다. 페이지가 ZIP 을 직접 열어 읽으며, Zip64 와 deflate 압축을 지원하고
`.thumbnails` 같은 점으로 시작하는 폴더는 걸러냅니다.

사진이 아주 많으면 아래 2번(PC)이나 3번(Termux)이 더 빠릅니다.
JPG·HEIC 의 EXIF와 구글 테이크아웃 메타데이터 JSON 을 읽으며, 사진은 브라우저 밖으로
나가지 않습니다. 기록은 localStorage 에 누적됩니다.

### 2. 폴더를 통째로 (자동)

사진이 PC 폴더에 있으면 고르는 단계 없이 한 번에 훑습니다. 표준 라이브러리만 씁니다.

```
python3 scan_photos.py ~/Pictures -o record.json
python3 scan_photos.py ~/DCIM -o record.json     # 안드로이드 DCIM 을 복사해 온 경우
```

하위 폴더까지 재귀적으로 읽고, 집계를 출력한 뒤 `record.json` 을 남깁니다.
그 내용을 지도 페이지의 `기록 백업 · 복원 · 초기화 → 붙여넣기로 복원` 에 붙여넣으면
지도가 채워집니다. 여러 폴더를 한 번에 넘겨도 됩니다.

동영상(`.mp4`/`.mov`/`.3gp`)도 읽습니다. 안드로이드·아이폰 모두 촬영 위치를
`udta` 의 `©xyz` 원자에 ISO6709 로 넣어두므로, 파일 양끝 4MB 만 읽어 좌표와 생성시각을
꺼냅니다 (동영상 전체를 읽지 않습니다).

DCIM 을 넘길 때 주의할 점:

- `.thumbnails` 처럼 점으로 시작하는 폴더는 건너뜁니다. 같은 사진의 축소본이 수천 장
  들어 있어 그대로 세면 방문 횟수가 부풀려집니다.
- `Screenshots` 는 원래 위치 정보가 없어 그대로 건너뛰며, 몇 개였는지 폴더별로
  보고합니다.
- **휴대폰을 USB 로 연결했을 때 보이는 MTP 경로는 실제 폴더가 아니라 읽을 수 없습니다.**
  `DCIM` 을 PC 안으로 복사한 뒤 그 경로를 넘겨주세요.

### 3. 스마트폰에서 직접 (안드로이드)

PC 없이 폰에서 바로 돌릴 수 있습니다. Termux 를 설치한 뒤:

```
pkg install python
termux-setup-storage          # 저장소 접근 권한 허용
cd ~/storage/shared
python3 scan_photos.py DCIM --html 내여행지도.html
```

`scan_photos.py`, `geo.json`, `travel_map.html` 세 파일을 같은 폴더에 두면 됩니다.
표준 라이브러리만 쓰므로 추가로 설치할 패키지가 없습니다. USB 연결이나 MTP 경로 문제도
없습니다 — 폰 안의 실제 경로를 그대로 읽습니다.

`--html` 로 만든 파일을 폰 브라우저로 열면 **지도가 이미 채워진 상태**로 뜹니다.
JSON 을 복사해 붙여넣는 단계가 필요 없습니다. 이 브라우저에 이미 쌓아둔 기록이 있으면
그쪽을 우선하므로 기존 기록을 덮어쓰지 않습니다.

아이폰은 사진을 파일로 노출하지 않아 이 방법을 쓸 수 없습니다. PC 로 동기화하거나
구글 테이크아웃 경로를 쓰세요.

### 지역 판정

`geo.json` 은 통계청 행정구역 경계(2013)를 단순화한 251개 시·군·구 폴리곤입니다.
좌표는 point-in-polygon 으로 판정하고, 해안·섬에서 경계를 살짝 벗어난 좌표는 60km 이내
최근접 시·군·구로 보정합니다. 서울(코드 11) 25개 구는 집계에서 빼고 지도에 빗금으로만
표시합니다.
