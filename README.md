# 왁뿌볼 뿌시기 (`wakppubol.html`)

캡슐 뽑기 장난감(왁뿌볼)을 직접 만들어서 제한 시간 안에 부수는 아케이드 게임입니다.
파일 하나로 끝나며, 더블클릭하면 브라우저에서 바로 실행됩니다. 설치할 것이 없습니다.
타격음으로 쓰는 녹음까지 파일 안에 들어 있어서 외부 의존성이 전혀 없습니다 (약 190KB).

## 게임 흐름

**1단계 — 왁뿌볼 만들기**
16색 색상표에서 **4가지 색**을 고르면 그 색으로 왁뿌볼이 만들어집니다.
고르는 즉시 오른쪽 미리보기에 반투명 캡슐 속 파스텔 알맹이가 회전하며 그려집니다.
`랜덤` 버튼으로 아무 색이나 뽑을 수도 있습니다.

**2단계 — 뿌시기**
**10초** 안에 **스페이스바를 연타**해서 껍질에 금을 내고 부숩니다.
누를 때마다 **장착한 도구를 휘둘러 왁뿌볼을 내려칩니다.** 균열이 실제로 껍질을 타고 뻗어 나가고,
다 채우면 왁뿌볼이 산산조각 납니다.

## 돈과 도구 상점

레벨을 하나 깰 때마다 **100점**을 법니다. 클리어하면 곧바로 상점 화면이 열리고,
모은 점수로 도구를 사서 장착한 뒤 다음 레벨로 넘어갑니다.

| 도구 | 가격 | 타격력 | 살 수 있는 시점 |
| --- | --- | --- | --- |
| ✊ 맨손 | 기본 | ×1.0 | — |
| 🔨 뿅망치 | 300점 | ×1.3 | Lv3 클리어 후 |
| ⛏️ 돌망치 | 500점 | ×1.6 | Lv5 클리어 후 |
| 🪓 은도끼 | 700점 | ×2.0 | Lv7 클리어 후 |
| ✨ 금도끼 | 1000점 | ×2.5 | Lv10 클리어 후 |

**타격력**은 스페이스바를 한 번 누를 때 들어가는 양입니다. 필요한 타격량 자체는 그대로이고,
좋은 도구를 들면 그만큼 적게 눌러도 됩니다. 예를 들어 Lv10은 51의 타격량이 필요한데
맨손이면 51번, 금도끼면 21번만 누르면 됩니다. 레벨 시작 화면에 **지금 도구로 몇 번 눌러야 하는지**가 표시됩니다.

도구를 사면 점수가 그만큼 줄어듭니다. 넷을 모두 사려면 2500점(약 25레벨)이 필요하므로,
싼 것을 일찍 사서 편하게 갈지 참았다가 좋은 것을 살지 고르게 됩니다.
지갑과 도구는 **한 판 안에서만 유지되고**, 게임 오버 후 다시 시작하면 맨손부터 시작합니다.
결과 화면과 최고 기록에 남는 **누적 획득**은 상점에서 써도 줄지 않습니다.

도구마다 타격음도 조금씩 다릅니다. 무거운 도구일수록 재생 속도가 낮아지고 소리가 커지며,
뿅망치는 장난감답게 "뿅" 하는 소리가 따로 얹힙니다.

## 휘두르는 동작

스페이스바를 누르면 도구가 **공 바로 위에서 감았다가 호를 그리며 내리꽂고, 반동으로 되돌아옵니다.**
전체 0.24초짜리 동작이고, 시작한 지 26% 지점(약 62ms)에서 껍질에 닿습니다.

| 구간 | 진행 | 팔 | 손목 |
| --- | --- | --- | --- |
| 감아 내리기 | 0 ~ 62ms | 0.95라디안 호를 **가속하며**(제곱 곡선) 내려온다 | 1.25라디안 감은 채로 **버틴다** |
| 스냅 | 55 ~ 62ms | — | 감아 둔 손목이 **확 풀리며** 머리가 채찍처럼 앞질러 나간다 |
| 타격 | 62ms | 타격량·소리·불꽃·화면 흔들림·공 밀림이 전부 이 순간에 일어난다 | |
| 팔로 스루 | 62 ~ 240ms | 감속하며(3차 곡선) 튕겨 올라간다 | 0.50라디안 넘어갔다가 다시 감기며 준비 자세로 |

### 손목 스냅을 어떻게 만들었나

도구를 통째로 돌리면 아무리 빨라도 뻣뻣합니다. 실제 망치질은 **팔뚝은 거의 그대로인데
손목을 축으로 머리만 늦게 따라오다 마지막에 확 풀리는** 채찍 운동입니다. 그래서 그림을 둘로 쪼갰습니다.

- `arm` — 팔뚝(소매). 손목보다 뒤라서 스냅에 회전하지 않습니다.
- `body` — 손 + 자루 + 머리. **손목 위치(`pivot`)를 축으로** 통째로 회전합니다.

손목 각도는 `1 - k⁵` 곡선을 씁니다. 5제곱이라 휘두르는 내내 거의 감긴 채로 버티다가
**마지막 10% 구간에서 한꺼번에 풀립니다.** 이 지연이 채찍 느낌을 만듭니다.
머리는 손목에서 멀리 떨어져 있어서, 같은 각속도라도 손보다 훨씬 빠르게 움직입니다.
대신 팔 전체의 회전량은 1.05에서 0.42라디안으로 줄여 손목이 주인공이 되게 했습니다.

**누르는 순간과 맞는 순간을 분리한 것이 핵심입니다.** 예전에는 타격을 첫 프레임에 두고
빼기만 해서 휘두르는 동작 자체가 없었습니다. 지금은 누르면 스윙이 시작되고
도구가 실제로 껍질에 닿을 때 타격이 처리됩니다.

- 누르는 즉시 **바람 소리**가 나고, 62ms 뒤 껍질이 깨지는 소리가 납니다. 소리가 동작을 따라갑니다.
- 휘두른 자리에 **궤적(스윙 자국)** 이 호로 남았다가 사라집니다.
- 타격이 늦게 처리되므로, **닿기 전에 다음 스페이스바가 들어오면 앞선 스윙을 먼저 처리**합니다.
  이 장치가 없으면 빠른 연타에서 입력이 사라집니다 (초당 66회까지 손실 없음을 확인했습니다).
- 시간이 다 된 뒤에 도착한 스윙은 무효 처리됩니다.
- 도구는 모두 캔버스에 직접 그렸습니다. 자루를 쥔 손과 소매가 함께 그려지고, 장착한 도구에 따라 머리 부분만 바뀝니다.
- 도끼날은 자루 쪽 목을 잘록하게 잡으면 술잔처럼 보여서, **뒷면을 자루 높이만큼 곧게 세우고** 앞쪽만 볼록한 호로 만들었습니다.
- **좌우를 번갈아 가며** 휘둘러서 연타처럼 보입니다. 매번 각도에 ±0.11 라디안의 난수가 섞입니다.
- 왼쪽에서 때릴 때는 회전만 시키면 엄지가 위로 올라가 손이 뒤집혀 보이므로, **상하로 미러링**합니다.
- 맞는 순간 도구는 진행 방향으로 13% 눌리고, 공은 반대쪽으로 반지름의 10%만큼 밀려납니다.
- 충격 이펙트(흰 선 9개 + 섬광)는 **도구보다 나중에 그립니다.** 먼저 그리면 도구에 완전히 가려집니다.
- 공이 작아지는 고레벨에서는 도구도 같이 작아집니다 (반지름의 0.62배에 도구별 배율).
- 이동 레벨에서 **놓친 채로 누른 헛스윙에는 도구가 나오지 않습니다.**

## 난이도 설계

| 항목 | 계산식 | 예시 |
| --- | --- | --- |
| 필요 연타 수 | `10 + (레벨-1) × 4.5` | Lv1 = 10회, Lv10 = 51회, Lv20 = 96회 (모두 10초 안에) |
| 제한 시간 | 항상 10초 | — |
| 이동 속도 | Lv5부터 `170 + (레벨-5) × 52` px/s | Lv5 = 170, Lv10 = 430, Lv20 = 950 |
| 공 크기 | Lv5부터 레벨당 5px씩 축소 (최소 66) | Lv5 = 170, Lv20 = 95 — 작아져서 더 잡기 어려움 |

**5레벨부터는 왁뿌볼이 도망칩니다.**
이때부터는 **마우스 왼쪽 버튼으로 왁뿌볼을 누른 채**로 연타해야 타격이 인정됩니다.

- 잡고 있으면 청록색 링이 생기고, 왁뿌볼은 저항하며 속도가 약 40%로 느려집니다.
- 대신 수시로 몸부림치며 방향을 확 틀어 손에서 빠져나가려 합니다.
- 놓친 상태에서 누른 연타는 무효이며, 놓친 동안에는 **이미 낸 금이 도로 아뭅니다**
  (초당 `1.0 + (레벨-5) × 0.09`회분).

## 소리

타격음은 **실제로 굳은 촛농이 깨지는 소리를 녹음한 것**입니다.
외부 파일을 불러오지 않고 HTML 안에 직접 심어서, 파일 하나만 열면 소리까지 그대로 납니다.

**샘플 뱅크 구조**
8.8초 원본 녹음에서 쓸 만한 순간만 골라 24kHz 모노 WAV 하나로 이어 붙이고,
재생할 때 구간(offset/duration)만 잘라 씁니다.

| 구간 | 내용 |
| --- | --- |
| 0.000 ~ 1.448초 | 타격음 7종 (각 0.2초, 8ms 간격) |
| 1.456 ~ 2.446초 | 파괴음 1종 (0.99초) |

**고르는 기준** — 원본에서 29개의 전이 지점을 뽑아 아래를 재고 걸렀습니다.

- 어택이 25ms 안쪽으로 날카롭게 서는가
- 직전 40ms가 조용해서 대비가 확보되는가 (5.8초 지점은 대비가 −2.4dB라 탈락)
- 스펙트럼 중심이 900Hz 위라 뭉개지지 않는가
- 정규화한 뒤에도 노이즈 플로어가 올라오지 않는가

12kHz 위 에너지가 3% 이하로 측정돼 24kHz(나이퀴스트 12kHz)로 담아도 손실이 없습니다.
파괴음은 가장 강한 크랙 0.28초 뒤에 부스러기 지속음 0.87초를 0.12초 겹쳐 이어 붙여 만들었습니다.

**재생 방식**

- 연타할 때마다 7종 중 하나를 무작위로 고르되, **직전에 쓴 것은 연속으로 나오지 않습니다.**
- 재생 속도에 `0.94~1.06`의 난수를 섞어 같은 샘플도 매번 조금씩 다르게 들립니다.
- 진행도가 오를수록 재생 속도가 최대 10% 높아지고 음량이 커져서, 껍질이 얇아지는 느낌을 줍니다.
- 파괴음은 원음에 0.68배로 느리게 깐 레이어를 겹쳐 무게를 더합니다.
- 연타해도 소리가 찢어지지 않도록 마스터 단에 다이내믹 컴프레서를 걸었습니다.
- 브라우저가 샘플을 디코딩하지 못하면 **자동으로 합성음으로 대체**됩니다
  (`synthSmash` / `synthBreak` — 필터 노이즈로 같은 질감을 흉내 낸 예비 코드).

## 그 밖의 규칙

- 목숨 3개. 시간 안에 못 부수면 하트 하나를 잃고 같은 레벨을 다시 도전합니다.
- 레벨을 깰 때마다 100점. 최고 기록(도달 레벨 · 누적 획득)은 브라우저에 저장됩니다.
- 스페이스바를 **꾹 누르고 있는 건 통하지 않습니다.** 키 자동 반복은 무시하므로 실제로 연타해야 합니다.
- 터치 기기에서는 화면 아래 `뿌시기` 버튼이 스페이스바를 대신합니다.

# 황산벌 전투 역사 퀴즈

초등학생이 풀 수 있는 **황산벌 전투(660년)** 객관식 퀴즈입니다.
두 가지 버전이 있습니다.

## 실행 방법

**HTML 버전** — 파일을 더블클릭하면 브라우저에서 바로 열립니다. 설치할 것이 없습니다.

**파이썬 버전**

```bash
python3 hwangsanbeol_quiz.py
```

파이썬 3만 있으면 되고, 따로 설치할 라이브러리는 없습니다.

## HTML 버전 화면

- **머리말**: 황산벌 들판 그림 — 왼쪽에 백제의 금빛 깃발 5개, 오른쪽에 신라의 푸른 깃발 20개로 병력 차이를 한눈에 보여 줍니다.
- **진격도**: 문제를 풀 때마다 깃발이 들판을 가로질러 앞으로 나갑니다.
- **문제 카드**: 문제마다 화면이 통째로 달라집니다. 12문제가 저마다 다른 삽화와 색을 가집니다.
  - 삽화 — 마주 선 두 진영, 계백 장군과 다섯 깃발, 창이 늘어선 신라 대군, 비어 있는 연도 두루마리,
    5 대 50 동그라미 비교, 들판의 이정표, 홀로 달려가는 화랑, 바다 건너 맺은 동맹,
    체크 넷과 가위표 하나가 그려진 방패, 한쪽으로 기운 저울, 해가 지는 성벽, 붓과 낙관
  - 색 — 문제마다 고유한 색상을 가지며, 카드 윗줄·진격 깃발·보기 번호·힌트 띠가 모두 그 색을 따릅니다
    (정답·오답 표시는 늘 초록·빨강으로 고정되어 헷갈리지 않습니다)
  - 갈래 — 문제 위에 인물 / 나라 / 숫자 / 땅 / 연도 / 사건 / 낱말 표시가 붙습니다
- **결과 화면**: 점수 원형 게이지, 계급(새내기 병사 ~ 삼국시대 박사), 오답 노트,
  병력 비교 그래프(동그라미 1개 = 군사 1,000명), 660년 사건 흐름 타임라인.
- 밝은 화면과 어두운 화면(다크 모드)을 모두 지원하고, 휴대폰 화면에도 맞춰집니다.

## 퀴즈 특징

- 총 12문제, 4지선다 객관식
- 문제 순서와 보기 순서가 매번 섞여서 나옴
- 답을 모를 때 `h`를 입력하면 힌트를 볼 수 있음
- 문제를 풀 때마다 쉬운 말로 된 해설이 나옴
- 마지막에 점수, 칭찬 메시지, 오답 노트를 보여 줌

## 화면 예시

```
[1/12번 문제] 황산벌 전투에서 백제 군사를 이끈 장군은 누구일까요?
  1. 김유신
  2. 계백
  3. 강감찬
  4. 을지문덕
정답 번호를 입력하세요 (힌트는 h): 2
⭕ 정답이에요! 잘했어요!
📖 백제의 계백 장군이 결사대를 이끌고 싸웠어요.
```

## 문제 추가하기

두 파일 모두 `QUESTIONS` 목록에 아래 형식으로 추가하면 됩니다.

```python
{
    "question": "문제 내용",
    "choices": ["보기1", "보기2", "보기3", "보기4"],
    "answer": "정답 보기",
    "hint": "힌트 문장",
    "explain": "해설 문장",
}
```

HTML 버전은 항목이 셋 더 있습니다.

- `scene` — 삽화 이름. `SCENES` 안의 `clash`, `gyebaek`, `yushin`, `year`, `troops`, `land`,
  `hwarang`, `allies`, `fourwins`, `outcome`, `fortress`, `word` 중에서 고르거나 새로 그려 넣습니다.
- `hue`, `sat` — 그 문제의 색(0~360의 색상값과 채도 %). 밝기는 화면 테마가 알아서 정하므로
  밝은 화면과 어두운 화면 모두에서 잘 보입니다.
- `tag` — 문제 갈래 (인물, 나라, 숫자, 땅, 연도, 사건, 낱말).
