# 🎹 자동 악보 넘기기 (Page Turner)

피아노 연주를 **마이크로 듣고**, 악보의 **박자(템포)** 와 함께 따져서 지금 어디를 치고 있는지 추적하고,
페이지 끝에 다다르기 직전에 **악보를 자동으로 넘겨 주는** 웹 앱입니다.
설치 없이 브라우저(크롬·엣지·사파리)에서 동작하며 태블릿에서도 쓸 수 있습니다.

## 실행 방법

마이크는 `https` 주소나 `localhost`에서만 쓸 수 있으므로 간단한 서버로 여는 것을 권장합니다.

```bash
cd page-turner
npm start            # → http://localhost:8000
```

(Node가 없다면 `python3 -m http.server 8000` 도 됩니다. 마이크 없이 “박자만” 모드나 데모만 쓸 거라면 `index.html`을 더블클릭해도 됩니다.)

1. **📂 악보 불러오기**로 MusicXML 악보를 엽니다. 파일을 화면에 끌어다 놓아도 됩니다.
2. **▶ 듣기 시작**을 누르고 마이크 사용을 허락한 뒤 연주를 시작합니다.
3. 연주를 따라 현재 마디가 파랗게 표시되고, 페이지 끝 2박 전(설정 가능)에 자동으로 넘어갑니다.

피아노가 없다면 **샘플 악보** → **🎵 데모 연주**로 체험할 수 있습니다. 데모는 일부러 악보 템포와 다르게,
템포를 흔들어 가며 연주하기 때문에 앱이 연주자의 속도를 따라가는 모습을 볼 수 있습니다.

### 📱 스마트폰·태블릿에 앱으로 설치하기 (PWA)

마이크를 쓰려면 `https` 주소가 필요하므로 먼저 GitHub Pages 같은 곳에 올립니다.
(저장소 **Settings → Pages → Deploy from a branch** 에서 이 브랜치와 `/ (root)` 를 고르면
`https://<아이디>.github.io/<저장소>/page-turner/` 주소가 생깁니다.)

| 기기 | 설치 방법 |
| --- | --- |
| 안드로이드 (크롬) | 주소를 연 뒤 위쪽의 **📲 앱 설치** 버튼, 또는 메뉴(⋮) → “앱 설치” / “홈 화면에 추가” |
| 아이폰·아이패드 (사파리) | 아래쪽 공유 버튼(□↑) → **“홈 화면에 추가”** (📲 버튼을 누르면 방법을 알려 줍니다) |
| PC (크롬·엣지) | 주소창 오른쪽의 설치 아이콘, 또는 📲 앱 설치 |

- 설치하면 홈 화면 아이콘으로 **주소창 없이 전체 화면**으로 열립니다.
- 한 번 열고 나면 앱 파일이 기기에 저장되어 **인터넷이 없는 연습실에서도** 동작합니다.
  (악보 파일은 기기에 있는 것을 불러오면 됩니다.)
- 새 버전을 올리면 앱 위쪽에 **🔄 새 버전** 버튼이 나타나고, 누르면 바뀝니다.
  앱 파일을 고쳤다면 `sw.js` 의 `VERSION` 을 올려 주세요.

### 그 밖의 기능

| 기능 | 방법 |
| --- | --- |
| 원하는 곳부터 시작 | 악보에서 마디를 누르면 그 마디부터 추적합니다 (연주 중에 눌러도 위치를 바로잡습니다) |
| 수동 넘김 | 화면 좌우의 ‹ › 버튼, 키보드 ←/→, PageUp/PageDown (블루투스 페이지 넘김 페달 호환) |
| 시작/정지 | Space 키 |
| 추적 방식 | ⚙ 설정 → 소리+박자(추천) / 박자만(메트로놈처럼) / 소리만 |
| 미리 넘기기 | 몇 박 전에 넘길지 (기본 2박) |
| 악보 크기, 마이크 민감도 | ⚙ 설정 |

화면 크기에 맞게 악보 줄을 “페이지”로 나누기 때문에 태블릿을 세우거나 눕혀도 알맞게 다시 나뉩니다.
연주 중에는 화면이 꺼지지 않게 합니다(지원하는 브라우저에서).

## 지원하는 악보 형식

- **MusicXML** (`.musicxml`, `.xml`) 과 압축 MusicXML (`.mxl`)
  - MuseScore, Finale, Sibelius, Dorico 등 대부분의 악보 프로그램에서 “MusicXML로 내보내기”가 됩니다.
  - [MuseScore.com](https://musescore.com), [IMSLP](https://imslp.org) 등에서 받은 악보도 MuseScore로 열어 내보내면 됩니다.
- **PDF·사진 악보**는 음표 정보가 없어 바로 읽을 수 없습니다. MuseScore의 “PDF 가져오기”나
  [Audiveris](https://github.com/Audiveris/audiveris) 같은 악보 인식(OMR) 프로그램으로 MusicXML로 바꾼 뒤 불러와 주세요.

악보에서 읽어 들이는 정보: 음 높이·길이, 화음, 여러 성부/보표(backup·forward), 붙임줄, 꾸밈음(무시),
박자표, 못갖춘마디, 템포(메트로놈 표기·`<sound tempo>`), 도돌이표와 1·2번 괄호.

## 어떻게 동작하나요 — “박자”와 “소리”를 함께 봅니다

```
마이크 ─▶ 소리 분석 ──(새 음의 시각 + 12음 크로마)──▶ 위치 추적기 ──(현재 박)──▶ 페이지 넘김
                                                      ▲
악보(MusicXML) ─▶ 연주 순서로 펼친 음 목록 + 템포 지도 ─┘
```

1. **악보 이해** (`js/score-model.js`)
   도돌이표를 펼쳐 실제 연주 순서대로 “동시에 치는 음 묶음(이벤트)” 목록을 만듭니다.
   각 이벤트는 박 위치, 악보 템포 기준 시각, 그리고 그 음들이 가진 12음(도~시) 에너지 분포(크로마)를 가집니다.

2. **소리 분석** (`js/audio-analyzer.js`)
   - 짧은 창의 스펙트럼에서 에너지가 갑자기 늘어나는 순간(spectral flux)을 찾아 **새 음을 친 순간(onset)** 을 감지합니다.
   - 긴 창의 스펙트럼에서 onset 직전과 직후의 차이, 즉 **새로 생긴 음들만의 크로마**를 구합니다.
     울리고 있는 앞 음(페달)의 영향을 줄여 줍니다.

3. **위치 추적** (`js/score-follower.js`)
   - **소리**: onset이 들릴 때마다 “지금 몇 번째 이벤트를 쳤을까”에 대한 확률 분포를 갱신합니다
     (은닉 마르코프 모델의 forward 단계). 들린 크로마가 악보 음과 얼마나 닮았는지, 그리고 직전 음 이후 흐른 시간이
     악보상 간격과 얼마나 맞는지를 함께 따지므로, 같은 선율이 반복되거나, 음을 틀리거나 빠뜨리거나, 잡음이 섞여도
     쉽게 흔들리지 않습니다.
   - **박자**: 가장 그럴듯한 위치에서 연주자의 템포만큼 시간이 흐르면 위치를 앞으로 보냅니다.
     그래서 긴 음표나 쉼표에서 소리가 없어도 페이지가 제때 넘어갑니다. 연주자의 템포는 최근 확인된 음들의
     (악보 시각, 실제 시각)에 직선을 맞춰 추정하므로 느리게/빠르게 치거나 점점 빨라져도 따라갑니다.
   - 안전장치: 소리로 확인되지 않은 음을 박자만으로 2개 넘게 앞서가지 않고, 1.5초 이상 조용하면(연주 멈춤)
     위치도 멈춥니다. 여러 번 연속으로 못 맞추면 주변 악보에서 위치를 다시 찾습니다.

4. **페이지 넘김** (`js/app.js`, `js/score-view.js`)
   “현재 위치 + 미리 넘기기 박” 지점이 다른 페이지에 있으면 그 페이지로 넘깁니다. 도돌이표로 앞 페이지로
   돌아가야 할 때도 같은 규칙으로 되돌아갑니다. 손으로 넘긴 페이지는 위치가 새 페이지로 넘어갈 때까지 존중합니다.

## 잘 쓰는 요령과 한계

- 마이크는 피아노 가까이, 다른 소리(대화, 음악)가 적은 곳에서 쓰면 가장 정확합니다.
  디지털 피아노라면 스피커 소리를 들려주면 됩니다.
- 음이 아주 빽빽한 빠른 패시지에서는 개별 음을 다 못 잡을 수 있지만, 박자 예측이 빈 곳을 메워 줍니다.
- 처음 몇 음은 템포를 모르므로 “시작 템포”(악보 템포가 기본값)를 실제 빠르기에 맞춰 두면 더 안정적입니다.
- D.C./D.S./Coda 같은 문자 지시는 아직 펼치지 않습니다 (도돌이표·1·2번 괄호는 지원).
- 여러 악기 총보도 읽을 수 있지만, 피아노 독주 악보에 맞춰 조정되어 있습니다.

## 파일 구조

```
page-turner/
├── index.html              화면
├── manifest.webmanifest    앱 설치 정보 (이름, 아이콘, 전체 화면)
├── sw.js                   서비스 워커 (오프라인 동작, 새 버전 알림)
├── icons/                  앱 아이콘
├── css/style.css
├── js/
│   ├── score-model.js      MusicXML 해석, 도돌이표 펼치기, 이벤트·템포 지도
│   ├── score-follower.js   위치 추적 (소리 + 박자)
│   ├── audio-analyzer.js   마이크 소리 → onset, 크로마, 음량
│   ├── score-view.js       악보 그리기(OpenSheetMusicDisplay), 화면 크기에 맞춘 페이지 나누기
│   ├── demo-player.js      데모 연주(합성음)
│   └── app.js              화면·버튼·자동 넘김 연결
├── samples/                샘플 악보 (환희의 송가 주제와 변주, 64마디)
├── tools/make-sample.js    샘플 악보 생성기
├── tests/                  단위 테스트, 브라우저 종단 테스트, 개발용 서버
└── vendor/                 OpenSheetMusicDisplay(BSD-3), JSZip(MIT) — 오프라인에서도 동작하도록 포함
```

## 테스트

```bash
cd page-turner
npm install
npm test            # 악보 해석 + 위치 추적 시뮬레이션 (느린/빠른/흔들리는 템포, 음 누락, 가짜 onset, 연주 멈춤)
npm run test:e2e    # (선택) 헤드리스 크롬에서 데모 연주를 실제로 분석해 따라가고 페이지가 제때 넘어가는지,
                    #        설치 가능한 앱으로 인정되고 오프라인에서도 열리는지 확인
```
