# 여행 발자국 (안드로이드 앱)

이 폰의 사진·동영상에서 촬영 위치를 읽어 다녀온 국내 시·군·구를 지도에 칠합니다.
서울은 제외합니다. 사진은 기기 밖으로 나가지 않습니다.

## 왜 앱이어야 하는가

안드로이드는 갤러리의 사진을 다른 앱에 넘길 때 EXIF 의 GPS 태그를 지웁니다. 브라우저도
예외가 아니라서, 웹페이지로는 기존 사진의 위치를 읽을 수 없습니다. 그 자리에서 카메라로
찍은 사진만 위치가 남는 것도 이 때문입니다.

`ACCESS_MEDIA_LOCATION` 권한을 가진 앱이 `MediaStore.setRequireOriginal()` 로 요청하면
지워지지 않은 원본을 받습니다. 이 앱은 그 한 가지를 하려고 존재합니다.

지역 판정 · 서울 제외 · 집계 · 지도 그리기는 `assets/travel_map.html` 이 그대로 맡습니다.
앱은 좌표만 모아 `window.__SCAN__` 으로 넘깁니다.

## 빌드

PC 에 Android Studio 를 설치한 뒤:

1. **Open** 으로 이 `android-app` 폴더를 엽니다 (상위 폴더 말고 이 폴더)
2. Gradle 동기화가 끝날 때까지 기다립니다. 버전이 맞지 않는다는 안내가 뜨면
   **AGP Upgrade Assistant** 의 제안을 그대로 받아들이면 됩니다
3. 폰을 USB 로 연결하고 개발자 옵션의 **USB 디버깅** 을 켭니다
4. **Run** (▶) 을 누르면 폰에 설치되고 실행됩니다

APK 파일만 뽑으려면 **Build → Build Bundle(s)/APK(s) → Build APK(s)**.
`app/build/outputs/apk/debug/app-debug.apk` 를 폰으로 옮겨 설치해도 됩니다.

## 사용

앱을 열고 **사진 훑어서 지도 만들기** 를 누릅니다. 권한을 두 가지 묻습니다.

- 사진·동영상 접근 — 목록을 읽기 위해
- **위치 정보 접근 — 반드시 허용해야 합니다.** 이걸 거부하면 안드로이드가 좌표를 지운
  사본을 넘겨줘서 지도가 비어 있게 됩니다

## 설정

`MainActivity.kt` 의 `dcimOnly` 가 `true` 면 DCIM 폴더(카메라로 찍은 것)만 훑습니다.
메신저로 받은 사진까지 모두 포함하려면 `false` 로 바꾸세요.

## 검증 상태

이 코드는 **빌드·실행 검증을 하지 못했습니다.** 작성 환경에 Android SDK 가 없고
`dl.google.com` 이 차단되어 있습니다. 구조와 API 사용은 검토했지만, 처음 빌드할 때
버전 관련 조정이 필요할 수 있습니다.

`assets/travel_map.html` 쪽(지도·집계·서울 제외)은 앱이 넘기는 것과 같은 형식의
`window.__SCAN__` 을 주입해 브라우저에서 검증했습니다.
