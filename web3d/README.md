# WebCraft 3D — Three.js + WebGL2 로 다시 지은 판

블록으로 만든 [WebCraft](../web/README.md) 를 **네모가 아닌 진짜 3D**로 옮긴 것입니다.
땅은 복셀이 아니라 높이맵을 그대로 삼각형으로 구운 곡면이고,
보잉 747도 상자를 쌓은 것이 아니라 단면을 이어 붙인 매끈한 동체입니다.

**같은 시드를 넣으면 블록판과 같은 자리에 공항과 도시가 섭니다.**
지형 노이즈와 부지 탐색 규칙을 그대로 옮겨 놨기 때문입니다.

- 결과물: **`dist/webcraft3d.html`** (파일 하나, 약 1.2 MB)
- 블록판은 그대로 `dist/minecraft.html` 로 남아 있습니다. 서로 건드리지 않습니다.

---

## 실행

`dist/webcraft3d.html` 을 **더블클릭**하면 브라우저에서 바로 열립니다.
Three.js 까지 파일 안에 들어 있어 인터넷이 필요 없습니다.

다시 빌드하려면:

```bash
node build3d.js      # web3d/ -> dist/webcraft3d.html
```

npm 은 필요 없습니다. Three.js 는 `web3d/vendor/three.bundle.js` 에 넣어 두었습니다
(만드는 방법은 [vendor/README.md](vendor/README.md), 라이선스는 MIT).

## 조작법

| 키 | 하는 일 |
| --- | --- |
| 화면 클릭 | 마우스 잠그기 (시점 조작 시작) |
| `WASD` | 이동 · `Space` 점프 · `Ctrl` 달리기 |
| `F` | 가까운 **비행기·열차 타기**. 아무것도 없으면 자유 비행 켜기/끄기 |
| `W`/`S` (비행 중) | 추력 올리기 / 내리기 |
| 마우스 (비행 중) | 기수 조종 · `A`/`D` 러더 · `Space` 지상 제동 |
| `Shift` | 내리기 (공중에서 내리면 낙하산) |
| `N` | 목적지 공항 바꾸기 / 자동 착륙 거절·해제 |
| `Y` | 자동 착륙 승인 |
| `V` | 1인칭 ↔ 3인칭 |
| `M` 지도 배율 · `R` 날씨 · `T` 시간 6시간 · `P` 화면 효과 | |

모바일: 화면 왼쪽을 끌면 이동, 오른쪽을 끌면 시점.

## 무엇이 3D 로 다시 만들어졌나

### 지형 — 복셀이 아니라 곡면

- `web/js/world.js` 의 높이 공식을 **반올림 없이** 그대로 써서 언덕이 매끄럽게 이어집니다.
- 플레이어 주위를 128블록짜리 타일로 덮되 멀수록 성기게 만듭니다
  (**LOD 5단계** — 한 변 64 → 32 → 16 → 8 → 4 분할). 시야는 약 1,400블록.
- 타일 가장자리에는 짧은 **치마(skirt)** 를 늘여 LOD가 다른 타일 사이의 틈을 가립니다.
- 색은 정점마다 **높이 · 기울기 · 기온 · 습도**로 정합니다 —
  해변 모래, 초원, 짙은 숲, 사막, 드러난 바위, 설선 위의 눈이 자연스럽게 섞입니다.
- 나무와 바위는 타일마다 **인스턴스 메시** 하나로 묶어 드로우콜을 아낍니다.

### 보잉 747 — 진짜 곡면 동체

- 단면(링) 14개를 이어 붙여 **기수 테이퍼 · 꼬리 업스윕**까지 있는 동체를 만듭니다.
- 747 특유의 **이층 혹**은 동체 위에 얹은 두 번째 단면 덩어리입니다.
- 날개는 평면도를 그려 얇게 눌러 만든 것이라 **뒤젖힘(sweep)과 상반각(dihedral)** 이 살아 있습니다.
- 엔진 네 개는 나셀 + 흡입구 링 + 팬 + 배기로 나뉘어 있고, 파일런으로 날개에 매답니다.
- 창문·도색 띠·꼬리 마크는 캔버스로 그린 텍스처입니다 (외부 이미지 없음).
- 착륙장치는 **접었다 폈다** 합니다.

### 하늘 · 바다 · 날씨

- 하늘은 Three.js 의 **대기 산란(Rayleigh · Mie) 셰이더**. 시간에 따라 아침놀·한낮·노을이 진짜로 물듭니다.
- **그림자** — 해를 따라 도는 방향광에 2048² 그림자맵.
- **바다** — 잔물결 네 겹으로 법선을 만들고 프레넬 반사와 해 반짝임을 넣은 셰이더.
  멀어질수록 잔물결을 재워 지글거림을 막습니다.
- **구름** — 도넛처럼 이어지는 3D 노이즈로 구운 텍스처가 두 겹으로 흐릅니다. 위로 올라가면 그 위로 나갑니다.
- **비와 눈** — 정점 셰이더가 위치를 계산하는 입자 5,000개. 추운 곳에서는 눈.
- **밤** — 별이 돌고, 건물 창문과 가로등에 불이 켜집니다 (emissive 맵).
- 후처리: **톤 매핑(ACES) → 블룸**. 톤 매핑을 먼저 하는 이유는 하늘의 HDR 값이
  그대로 블룸에 들어가면 화면 전체가 뿌옇게 씌워지기 때문입니다.

### 공항 · 도시 · 철도

블록판과 **같은 좌표, 같은 규모**로 서되 건축물로 다시 지었습니다.

- **공항** — 활주로 2본(중심선·가장자리선·접지대 피아노 건반·진입등),
  유도로와 계류장, 곡면 지붕 터미널(유리 커튼월 + 실내 시설), 탑승교 12개,
  원뿔형 **관제탑**과 표지등.
- **도시** — 격자 도로와 인도·가로등, 유리 커튼월 고층 빌딩, 공원.
  · **김포** — 팔각 단면이 좁아지며 첨탑까지 솟는 **롯데타워**(약 230블록, 도시에서 가장 높다)
  · **제주** — 현무암 기단 · 흰 벽 · **주황 기와 모임지붕**, 돌담 두른 귤밭, 돌하르방과 정자
  · **인천** — 송도풍 유리 신도시와 전망탑
- **공항철도** — 교각 위 고가 선로, 유리벽 승강장, 2량 전동차가 오갑니다.
  역에서 9초 쉬었다 되돌아가고, `F` 로 타면 객실에서 창밖을 봅니다.

### 비행

블록판의 아케이드 비행 모델을 그대로 옮기되 자세(피치·롤)가 실제로 기웁니다.

- **자동 착륙** — 목적지까지 500m가 남으면 승인 창이 뜨고,
  승인하면 활주로 진입선에 정렬해 3도 활공각으로 내려와 접지·감속까지 합니다.
- **관제탑 신호** — 계기판에 목적지·거리·방위 화살표.
- 공중에서 내리면 **낙하산**이 펴집니다.

## 블록판과 다른 점

| | 블록판 (`dist/minecraft.html`) | 3D판 (`dist/webcraft3d.html`) |
| --- | --- | --- |
| 렌더러 | 직접 짠 WebGL 1.0 | Three.js r185 + WebGL2 |
| 땅 | 복셀 블록 | 높이맵 곡면 (LOD) |
| 캘 수 있나 | **예** — 캐고 놓고 만들고 | 아니요 (복셀이 아니라 캘 대상이 없습니다) |
| 인벤토리·제작·화로 | 있음 | 없음 |
| 주민·거래 | 있음 | 없음 |
| 가구 32종 | 있음 | 공항 실내에 간략화해서 들어감 |
| 비행·공항·도시·철도 | 있음 | 있음 (같은 좌표) |
| 그림자·대기 산란·블룸 | 간이 | 제대로 |
| 파일 크기 | 약 0.7 MB | 약 1.2 MB |

**복셀을 버리면 캐고 쌓는 놀이도 함께 사라집니다.** 그래서 두 판을 따로 두었습니다 —
블록판은 만드는 게임, 3D판은 날고 돌아다니는 게임입니다.

## 코드 구조

```
web3d/
├── index.html            시작 화면 · HUD 뼈대
├── css/style3d.css       HUD 스타일
├── vendor/
│   └── three.bundle.js   Three.js r185 + 애드온 (npm 없이 빌드하려고 넣어 둠)
└── js/
    ├── noise.js          블록판과 같은 시드 난수 · 펄린 노이즈
    ├── world3d.js        높이 공식 · 생물 군계 · 평탄화 구역
    ├── places3d.js       공항 3곳 · 도시 3곳 자리 고르기 (블록판과 같은 규칙)
    ├── textures3d.js     캔버스로 그리는 텍스처 (아스팔트·유리·기와·도색…)
    ├── models3d.js       747 · 전동차 — 단면을 이어 붙인 곡면 모델
    ├── terrain3d.js      LOD 지형 타일 · 나무와 바위 인스턴싱
    ├── structures3d.js   공항 · 도시 · 고가철도 (같은 재질끼리 지오메트리 병합)
    ├── sky3d.js          대기 산란 하늘 · 해와 달 · 별 · 구름 · 바다 · 날씨
    ├── flight3d.js       비행 물리 · 자동 착륙 · 열차 운행
    ├── game3d.js         게임 루프 · 카메라 · 조작 · HUD · 지도
    └── boot3d.js         시작 화면 처리
```

## 동작 환경

WebGL2 를 지원하는 브라우저면 됩니다 (크롬·엣지·파이어폭스·사파리 15+, 안드로이드 크롬,
iOS 사파리 15+). 화질은 시작 화면에서 **높음 / 보통 / 낮음** 중에 고를 수 있고,
낮음은 그림자와 블룸을 끄고 픽셀 비율을 1로 낮춥니다.
