# WebCraft — 웹뷰에서 도는 마인크래프트

자바 마인크래프트를 참고해 **처음부터 직접 만든 복셀 게임**입니다.
게임 엔진, 지형 생성, 조명, 렌더러, 텍스처, 아이템 아이콘까지 전부 이 저장소 안의 코드로 만들어졌습니다.

- **외부 라이브러리 0개** — Three.js도, 번들러도, npm 패키지도 쓰지 않습니다. 순수 WebGL 1.0 + 바닐라 JS.
- **외부 이미지 0개** — 블록 텍스처와 아이템 아이콘을 실행할 때 픽셀 단위로 그립니다.
- **네트워크 0회** — 파일 하나만 있으면 비행기 모드에서도 돌아갑니다. 웹뷰에 그대로 넣으면 됩니다.

---

## 실행 방법

### 1. 가장 간단한 방법 (권장)

`dist/minecraft.html` **파일 하나만** 있으면 됩니다. 더블클릭하면 브라우저에서 바로 열립니다.

안드로이드 `WebView`, iOS `WKWebView`, 일렉트론 등에 넣을 때도 이 파일 하나면 충분합니다.

```java
// 안드로이드 WebView 예시
webView.getSettings().setJavaScriptEnabled(true);
webView.loadUrl("file:///android_asset/minecraft.html");
```

```swift
// iOS WKWebView 예시
let url = Bundle.main.url(forResource: "minecraft", withExtension: "html")!
webView.loadFileURL(url, allowingReadAccessTo: url.deletingLastPathComponent())
```

### 2. 원본 소스로 실행

`web/index.html`을 브라우저에서 열면 됩니다. 파일을 직접 열어도 동작하지만,
로컬 서버로 여는 편이 더 안전합니다.

```bash
cd web
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

### 3. 소스를 고친 뒤 단일 파일 다시 만들기

```bash
node build.js      # web/ 의 CSS·JS를 전부 인라인해서 dist/minecraft.html 생성
```

돌·잔디·흙·조약돌·기반암·모래·자갈·판자(참나무/자작나무/가문비나무)·원목 3종·잎 3종·유리·물,
석탄/철/금/다이아몬드/레드스톤/청금석/에메랄드 광석,
제작대·화로·상자·횃불, 사암·벽돌·돌벽돌·이끼 낀 조약돌·흑요석·눈·얼음·선인장·점토·호박·수박·책장·TNT,
철/금/다이아몬드/에메랄드/청금석/석탄/레드스톤 블록, 발광석·네더랙·소울모래,
민들레·양귀비·풀·버섯 2종·죽은 덤불·사탕수수·묘목 3종, 경작지와 밀 4단계, **양털 16색**, 스펀지, 소리 블록.

도구의 **내구도·채굴 속도·공격력**, 방어구의 **방어도**, 음식의 **허기·포화도** 모두 원본 수치를 따랐습니다.

```

  맨손 7.5초 · 나무 곡괭이 1.15초 · 돌 0.75초 · 철 0.5초 · 다이아몬드 0.25초

```

### 제작 129가지 + 제련 13가지

- **모양 있는 제작**: 도구·방어구·제작대·화로·상자·횃불·활·양동이·가위처럼 배치가 중요한 것들.
- **모양 없는 제작**: 원목→판자, 블록↔재료 압축·해체 등.
- 인벤토리에서는 2×2, 제작대를 열면 3×3 격자를 씁니다.
- 화로는 연료를 태워 광석을 주괴로, 모래를 유리로, 생고기를 익힌 고기로 바꿉니다.
  석탄 1개 = 80초, 제련 1회 = 10초로 원본과 같습니다.

### 세계

- **바이옴 7종** — 바다, 해변, 평원, 숲, 사막, 산, 설원. 온도·습도 노이즈로 나뉩니다.
- 프랙탈 펄린 노이즈로 만든 지형에 3차원 노이즈로 **동굴**을 뚫고, 깊이에 따라 **광맥**을 심습니다.
- 바이옴마다 다른 나무(참나무·자작나무·가문비나무), 선인장, 사탕수수, 꽃, 버섯이 자랍니다.
- **하늘빛과 블록빛을 따로 계산하는 조명** — 횃불을 놓으면 빛이 15칸까지 번져 나가고,
  블록을 부수면 그 자리로 빛이 다시 흘러듭니다. 면마다 부드러운 조명과 앰비언트 오클루전이 들어갑니다.
- **20분 낮밤 주기** — 해가 지면 어두워지고 노을이 집니다.
- 모래·자갈은 아래가 비면 떨어지고, 잔디는 흙으로 번지며, 밀은 밝은 곳에서 자랍니다.

언데드는 아침 햇빛을 받으면 불타 죽습니다.

### 플레이어

체력 20(하트 10개) · 허기 20 · 산소 · 방어도, 낙하 피해, 익사, 굶주림, 자연 회복,
아이템을 떨어뜨리고 줍기, 죽으면 소지품을 떨어뜨리고 리스폰.

### 저장

60초마다, 그리고 창을 닫을 때 `localStorage`에 자동 저장됩니다.
플레이어가 손댄 청크만 런랭스 압축해서 저장하므로 용량이 작습니다.
시작 화면의 **이어하기**로 불러옵니다.

## 코드 구조

```
web/
├── index.html          시작 화면과 HUD 뼈대
├── css/style.css       HUD·인벤토리·터치 조작 스타일
└── js/
    ├── noise.js        시드 난수, 펄린 노이즈, 프랙탈 노이즈
    ├── blocks.js       블록 85종의 성질 (단단함, 필요 도구, 드랍, 발광...)
    ├── items.js        아이템 172종 (도구 성능, 방어도, 음식 수치)
    ├── textures.js     블록 텍스처를 픽셀 단위로 그려 256×256 아틀라스로 합침
    ├── itemicons.js    아이템 아이콘 생성 (도구는 픽셀 아트, 블록은 아이소메트릭 큐브)
    ├── glutil.js       4×4 행렬 수학, 셰이더 컴파일, 셰이더 소스
    ├── world.js        청크, 지형 생성, 빛 전파, 메시 생성, 레이캐스트
    ├── player.js       물리, 충돌, 채굴 공식, 인벤토리, 체력·허기
    ├── mobs.js         엔티티 AI, 몹 모델, 떨어진 아이템
    ├── crafting.js     제작·제련 레시피와 격자 매칭
    ├── renderer.js     WebGL 렌더러 (하늘, 청크, 엔티티, 외곽선, 절두체 컬링)
    ├── ui.js           HUD와 인벤토리·제작대·화로·상자 화면
    ├── main.js         게임 루프, 입력, 상호작용, 저장/불러오기
    └── boot.js         시작 화면 처리
```

### 기술적으로 눈여겨볼 부분

- **청크** 16 × 96 × 16. 지형 생성 → 장식 → 조명 → 메시 생성 순서로,
  프레임마다 **시간 예산(기본 7ms)** 만큼만 처리해 느린 기기에서도 화면이 끊기지 않습니다.
- **나무가 청크 경계에서 잘리지 않도록**, 각 청크는 이웃 3×3 청크의 장식 목록을
  같은 시드로 다시 계산해서 자기 범위에 걸치는 부분만 기록합니다.
- **조명**은 청크 경계를 넘나드는 BFS로 전파합니다. 블록을 부수거나 놓으면
  기존 빛을 되돌린 뒤(unpropagate) 다시 채웁니다.
- **면 컬링 + 부드러운 조명 + AO**를 메시 생성 때 정점에 구워 넣어 셰이더를 가볍게 유지합니다.
- 불투명 청크는 **앞→뒤**로, 물은 **뒤→앞**으로 정렬해 그립니다.
- 몹과 떨어진 아이템은 매 프레임 하나의 동적 버퍼로 합쳐 **드로우콜 2번**에 그립니다.

## 원본과 다른 점

되도록 원본에 맞췄지만, 웹 한 파일로 만들면서 다음은 다르게 했습니다.

- **물이 흐르지 않습니다.** 물은 고정된 블록이라 양동이로 놓으면 그 자리에만 생깁니다.
- **레드스톤 회로가 없습니다.** 레드스톤은 재료와 블록으로만 존재합니다.
- **네더·엔드 차원이 없습니다.** 네더랙·발광석 등은 창작 모드 아이템으로만 있습니다.
- **문·계단·반블록처럼 정육면체가 아닌 블록**은 넣지 않았습니다 (렌더러가 정육면체·십자·액체만 다룹니다).
- **쿠키**는 코코아콩이 없는 세계라 `밀 2 + 설탕 1`로 만듭니다.
- **양털 염색**은 염료 대신 광물·꽃을 하양 양털과 조합합니다 (예: 하양 양털 + 청금석 = 파랑 양털).
- **소리**는 캐기·놓기 두 가지 효과음만 코드로 합성해 냅니다.

## 내용 추가하기

**블록 추가** — `blocks.js`에 한 줄, `textures.js`에 그리는 함수 하나면 끝입니다.
아이템·아이콘·창작 모드 목록은 자동으로 만들어집니다.

```js
// blocks.js
defBlock(86, 'my_block', '내 블록', {
  hardness: 3, tool: TOOL_PICKAXE, tier: 2, light: 7
});

// textures.js 의 registerBlockTextures() 안
defTex('my_block', function (p, rnd) {
  p.noise(rnd, '#8844cc', 12, 4);
  p.speckle(rnd, '#ffffff', 10);
});
```

**레시피 추가** — `crafting.js`에 한 줄.

```js
shaped(['DDD', 'DSD', 'DDD'], { D: 'diamond', S: 'stick' }, 'my_block', 1);
shapeless(['coal', 'stick'], 'torch', 4);
smelt('my_block', 'diamond');
```

고친 뒤 `node build.js`로 단일 파일을 다시 만들면 됩니다.

## 동작 환경

WebGL 1.0을 지원하는 브라우저면 됩니다. 안드로이드 WebView(Chrome 기반), iOS WKWebView,
데스크톱 Chrome·Edge·Firefox·Safari에서 동작합니다.
`OES_element_index_uint` 확장이 있으면 자동으로 32비트 인덱스를 써 큰 청크도 한 번에 그립니다.

시작 화면에서 **렌더 거리**를 3~12 사이로 조절할 수 있습니다. 기기가 버거우면 낮추세요.
