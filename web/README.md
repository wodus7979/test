# WebCraft — 웹뷰에서 도는 마인크래프트

자바 마인크래프트를 참고해 **처음부터 직접 만든 복셀 게임**입니다.
게임 엔진, 지형 생성, 조명, 렌더러, 텍스처, 아이템 아이콘까지 전부 이 저장소 안의 코드로 만들어졌습니다.

- **공항 세 곳과 보잉 747** — 인천·김포·제주 공항이 아주 멀리 떨어져 생기고, 747을 타고 직접 날 수 있습니다.
  정기편 두 대가 공항 사이를 스스로 오갑니다.
- **오른쪽 위 지도** — 지형·공항·마을·비행기를 한눈에.
- **구름과 날씨** — 하늘에 구름이 흐르고, 비와 눈이 내리고, 추운 곳에서는 나무와 지붕에 눈이 쌓입니다.
- **주민 마을과 거래** — 우물·길·집 9종·밭이 있는 마을이 생기고, 15가지 직업의 주민이 돌아다닙니다.
- **화면 셰이더** — 블룸·갓레이·톤 매핑·해와 달과 별. 4단계로 끄고 켤 수 있습니다.
- **외부 라이브러리 0개** — Three.js도, 번들러도, npm 패키지도 쓰지 않습니다. 순수 WebGL 1.0 + 바닐라 JS.
- **외부 이미지 0개** — 블록 텍스처와 아이템 아이콘을 실행할 때 픽셀 단위로 그립니다.
- **네트워크 0회** — 파일 하나만 있으면 비행기 모드에서도 돌아갑니다. 웹뷰에 그대로 넣으면 됩니다.

## 실행 방법

### 1. PC에 파일로 설치 (가장 편한 방법)

`dist/minecraft.html` **파일 하나만** 있으면 됩니다. 원하는 폴더에 두고 **더블클릭**하면 끝입니다.
설치 프로그램도, 인터넷도, 다른 파일도 필요 없습니다.

바탕화면에 바로가기를 만들어 두면 게임처럼 쓸 수 있습니다.

| 운영체제 | 방법 |
| --- | --- |
| 윈도우 | `minecraft.html` 우클릭 → **보내기 → 바탕 화면(바로 가기 만들기)** |
| 맥 | `minecraft.html` 우클릭 → **별칭 만들기** 후 원하는 곳으로 옮기기 |
| 리눅스 | 파일 관리자에서 링크 만들기 |

저장소를 함께 받았다면 `run/` 폴더의 실행 파일을 더블클릭해도 됩니다.

```
run/윈도우에서-실행.bat        윈도우
run/맥에서-실행.command        맥 (처음 한 번 chmod +x 필요할 수 있음)
run/리눅스에서-실행.sh         리눅스
```

**전체 화면으로 하고 싶으면** 브라우저에서 `F11`(맥은 `Ctrl+Cmd+F`)을 누르세요.

### 2. 웹뷰에 넣기

같은 파일 하나를 그대로 넣으면 됩니다.

```java
// 안드로이드 WebView 예시
webView.getSettings().setJavaScriptEnabled(true);
webView.getSettings().setDomStorageEnabled(true);   // ← 이걸 켜야 자동 저장이 됩니다
webView.loadUrl("file:///android_asset/minecraft.html");
```

```swift
// iOS WKWebView 예시
let url = Bundle.main.url(forResource: "minecraft", withExtension: "html")!
webView.loadFileURL(url, allowingReadAccessTo: url.deletingLastPathComponent())
```

### 3. 원본 소스로 실행

`web/index.html`을 브라우저에서 열면 됩니다. 파일을 직접 열어도 동작하지만,
로컬 서버로 여는 편이 더 안전합니다.

```bash
cd web
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

### 4. 소스를 고친 뒤 단일 파일 다시 만들기

```bash
node build.js      # web/ 의 CSS·JS를 전부 인라인해서 dist/minecraft.html 생성
```

### 블록 모양 (정육면체가 아닌 블록)

렌더러가 **상자 목록 모델**을 지원해서 다음이 실제 모양대로 놓이고, 그 모양대로 충돌합니다.

- **계단** — 설치할 때 보는 방향으로 회전, 아랫면을 클릭하면 뒤집힌 계단
- **반블록** — 아래/위 절반, 위에 올라서면 딱 0.5칸만 올라감
- **울타리 · 벽 · 유리판 · 철창** — 이웃과 자동으로 이어짐
- **문 · 다락문 · 울타리문** — 우클릭으로 여닫기 (문은 위아래 두 칸이 함께 움직임)
- **카펫 · 압력판 · 버튼 · 눈층 · 레일** — 밟고 지나갈 수 있는 얇은 판
- **횃불 · 양초 · 랜턴 · 사슬 · 엔드 막대 · 사다리 · 화분 · 케이크 · 모루 · 가마솥 · 깔때기 · 침대**

색유리·얼음·슬라임·꿀 블록은 알파 블렌딩 패스로 그려 **뒤가 실제로 비쳐 보입니다.**

### 물리 — 물과 용암이 실제로 흐릅니다

**물 바로 앞 땅을 파면 물이 그 방향으로 흘러나옵니다.** 원본과 같은 방식으로 계산합니다.

- **수원과 흐르는 물** — 수원(단계 0)에서 옆으로 퍼질 때마다 단계가 1 내려가고, 7이 되면 멈춥니다.
  그래서 물은 수원에서 최대 7칸까지 퍼집니다. 단계가 커질수록 수면이 낮아지고, 꼭짓점 높이를
  이웃과 평균해 **수면이 자연스럽게 기울어집니다.**
- **낭떠러지를 찾아 흐릅니다** — 옆으로 퍼질 때 5칸 안에서 아래로 떨어질 수 있는 곳까지의
  최단 경로를 너비 우선 탐색으로 찾아, 그 방향으로 먼저 흘러갑니다. 평지에서는 사방으로 퍼집니다.
- **떨어지는 물** — 아래가 비면 먼저 떨어지고, 떨어지는 물은 바닥에서 다시 수원처럼 퍼집니다.
- **저절로 마릅니다** — 수원을 없애면 단계가 하나씩 올라가며 흐르던 물이 전부 사라집니다.
- **무한 물** — 수원 2개가 붙어 있으면 사이의 흐르는 물이 새 수원이 됩니다.
- **물살이 밀어냅니다** — 흐르는 방향으로 플레이어가 밀립니다.
- **씻겨 나갑니다** — 물이 지나가면 풀·꽃·횃불·카펫·레일이 아이템으로 떨어집니다.
- **용암** — 단계가 2씩 내려가 3칸만 퍼지고, 물보다 6배 느리게(30틱) 흐릅니다.
  물에 닿으면 수원은 **흑요석**, 흐르는 용암은 **조약돌**로 굳습니다. 안에 들어가면 아주 느려지고 아픕니다.
- **콘크리트 가루**가 물에 닿으면 콘크리트로 굳습니다.

계산은 원본처럼 **예약 갱신 방식**입니다. 블록이 바뀐 자리 주변만 큐에 넣고, 물은 5틱·용암은 30틱
뒤에 다시 계산합니다. 한 틱에 처리할 개수를 제한해서 큰 호수를 터뜨려도 프레임이 끊기지 않습니다.

### 주민 마을

평원·숲·설원·사막 어디든 **320블록마다 한 자리씩** 마을 후보가 잡히고, 그중 지형이 알맞은
곳에만 마을이 섭니다 (바다·산비탈·너무 울퉁불퉁한 곳은 건너뜁니다). 시드만 같으면 마을 위치와
생김새까지 똑같이 나옵니다.

- **터를 고릅니다** — 반지름 32블록 안쪽 62%는 완전히 평탄하게 밀고, 바깥은 원래 지형으로
  부드럽게 이어 붙입니다. 그 위에 서 있던 나무·풀·눈은 치웁니다.
- **우물이 한가운데** — 조약돌 물통, 네 기둥, 슬래브 지붕, 그리고 **종**이 있습니다.
  거기서 길이 사방으로 뻗고, 길가 자리마다 집이 섭니다.
- **집 9종** — 작은 집·집·도서관·대장간·푸줏간·교회·화살 장인·석공·지도 제작소.
  기초는 조약돌, 벽은 판자에 모서리는 원목, 지붕은 계단 블록으로 짠 **박공 지붕**입니다.
  안에는 침대·제작대·화로·모루·책장·연마석 같은 직업 도구가 들어 있고, 창에는 유리판이 끼워집니다.
- **밭** — 울타리를 두르고 가운데 물골을 낸 뒤, 밀·당근·감자·비트 중 하나를 자라는 단계를 섞어 심습니다.
- **가로등** — 울타리 기둥 위 횃불. 밤이면 마을만 환합니다.
- **생물 군계별 자재** — 평원은 참나무+조약돌, 설원과 숲은 가문비나무, 사막은 사암과 아카시아 문.

마을 도면은 청크마다 다시 계산하지 않고 **한 번 만들어 청크별로 나눠 캐시**합니다.
세로로 이어진 기둥은 한 덩어리로 묶어 저장해서, 마을 하나가 약 1만 1천 개의 명령으로 줄어듭니다.

### 주민과 철 골렘

- **직업 15가지** — 백수·멍청이·농부·어부·양치기·화살 장인·사서·지도 제작자·성직자·갑옷 장인·
  무기 장인·도구 장인·푸줏간 주인·석공·가죽 세공사. 직업마다 겉옷과 앞치마 색이 다릅니다.
- **마을을 벗어나지 않습니다** — 집에서 26블록 안을 어슬렁거리고, 멀어지면 안쪽으로 방향을 틉니다.
  밤이 되면 우물 쪽으로 모입니다.
- **가까이 가면 쳐다봅니다.** 몬스터가 9블록 안에 들어오면 반대 방향으로 달아납니다.
- **거래** — 주민에게 **우클릭**하면 거래창이 열립니다. **에메랄드가 마을의 돈**입니다.
  농부에게 밀 20개를 주면 에메랄드가 되고, 대장장이에게 에메랄드를 주면 철 검이 나옵니다.

- **철 골렘** — 주민이 3명 이상 모인 마을에 한 마리가 섭니다. 체력 100, 몬스터를 보면 쫓아가
  14 피해로 후려쳐 하늘로 띄웁니다. 플레이어는 공격하지 않습니다.
- **찾아가기** — 시작 화면의 **"마을에서 시작"** 을 켜면 가까운 마을 어귀에서 시작합니다.
  게임 중에는 **F3**에 가장 가까운 마을의 좌표와 거리가 나옵니다.

**인천(ICN) · 김포(GMP) · 제주(CJU)** 가 세계마다 하나씩 생깁니다.
각자 정해진 방향으로 멀찍이 떨어진 곳에서 평평하고 넓은 자리를 찾아 짓기 때문에
**공항 사이가 5,000~10,000블록**이나 됩니다. 시속 200km로 날아 3~4분 걸리는 거리라
비행이 "이동"이 아니라 "여행"이 됩니다.

- **활주로 2본** (260 × 15블록). 가장자리 선, 중심선 파선, 착륙지대 피아노 건반,
  도트 글꼴로 찍은 활주로 번호(15/33 · 16/34), 12칸마다 바다 랜턴 등화,
  그리고 양 끝으로 뻗은 **진입등** — 하늘에서 활주로를 찾는 표지입니다.
- **유도로**와 **계류장**, 주기장 12자리와 노란 유도선.
- **터미널** 132 × 27 × 15 — 하늘색 유리 커튼월과 석영 기둥, 곡면 지붕 위 공항 코드.
- **탑승교 12개**가 터미널에서 주기장까지 뻗어 비행기와 붙습니다.
- **관제탑** — 30블록 기둥 위 유리 관제실, 꼭대기에 표지등. 사다리로 오를 수 있고
  관제사 두 명이 근무합니다.

**땅 고르기는 도면에 담지 않고 청크를 찍는 순간 계산**합니다. 활주로·계류장·관제탑을
감싸는 사각형들의 합집합만 평탄하게 만들고 가장자리에서 원래 지형으로 이어 붙이므로,
공항 한 곳의 도면이 5만 4천 개 명령으로 끝납니다 (세 곳 다 만드는 데 0.2초).

### 보잉 747 — 조종과 자동 운항

주기장에 **네 대**가 세워져 있고, 그 밖에 **정기편 두 대**가 공항 사이를 쉬지 않고 오갑니다.

| 조작 | 하는 일 |
| --- | --- |
| 우클릭 | 탑승 |
| `W` / `S` | 추력 올리기 / 내리기 |
| 마우스 | 기수를 그쪽으로 돌린다 |
| `A` / `D` | 러더 |
| `Space` | 지상 제동 |
| `Shift` | 내리기 — **하늘에서 누르면 낙하산이 펴집니다** |
| `N` | 목적지 공항 바꾸기 |

- **카메라는 언제나 비행기 바로 뒤**를 따라갑니다. 마우스로 기수를 돌리면 카메라가
  부드럽게 따라 돌아가고, 선회할 때는 기체와 함께 살짝 기웁니다.
- **관제탑 신호** — 계기판 아래쪽에 목적지 공항 이름·거리·방위 화살표가 뜹니다.
  700블록 안으로 들어가면 **활주로 중심선 편차 막대**와 **활공각 안내**가 켜져
  ("활공각보다 높음 / 낮음 / 진입 양호 ✔") 그대로 따라가면 착륙할 수 있습니다.
- **낙하산** — 공중에서 내리면 저절로 펴집니다. 초속 4.5m로 천천히 내려오고
  낙하 피해가 없으며, WASD로 방향을 잡을 수 있습니다. 머리 위 캐노피가 보입니다.
- **경보** — 다른 비행기가 130블록 안에 들어오면 노란 경보, 55블록 안이면
  빨간 충돌 경보가 화면 위에 뜨고 경고음이 납니다. 내려가는 중에 땅이 가까우면
  **대지 접근 경보**가 뜹니다.
- **정기편 두 대**는 주기 → 유도로 → 이륙 → 상승 → 순항 → 강하 → 최종 진입 →
  착륙 → 유도로 → 주기를 스스로 반복합니다. 활주로 중심선을 겨누고 3도 활공각으로
  내려오며, 활주로를 지나치면 복행해서 다시 들어옵니다. 플레이어가 어디에 있든
  계속 날기 때문에 공항에 앉아 있으면 실제로 뜨고 내리는 걸 볼 수 있습니다.

### 오른쪽 위 지도

- 실제로 불러온 청크의 **맨 위 블록 색**을 그대로 써서 그립니다
  (색은 텍스처의 평균색이라 블록을 추가해도 저절로 맞습니다). 높낮이에 따라 음영이 집니다.
- **공항**은 화면 밖에 있어도 가장자리에 붙어 코드와 거리를 보여 주고,
  지금 목적지로 잡은 공항은 초록색입니다. **마을**은 주황 점, **비행기**는 삼각형
  (정기편은 노랑), 가운데 빨간 화살표가 나입니다.
- `M` 키로 배율을 1:1 → 1:2 → 1:4 → 1:8 로 바꿉니다.
- 청크 타일은 한 번 만들어 캐시하고 블록이 바뀐 청크만 다시 그립니다.

### 하늘 · 구름 · 날씨

**구름** — 원작처럼 높이 84에 떠 있는 납작한 덩어리입니다. 시드에서 만든 40×40 격자를
도넛처럼 감아서 세 번 다듬어 뭉게뭉게한 모양을 만들고, 이웃과 맞닿은 옆면은 빼고 메시로 굽습니다.
한 판이 560블록마다 반복되지만 **거리에 따라 하늘색으로 사라지게** 해서 반복이 눈에 띄지 않습니다.
플레이어 주위 3×3판만 그리고 절두체 밖은 건너뛰므로 비용은 삼각형 5천 개 남짓입니다.
초당 0.55블록씩 천천히 흘러가고, 구름 속으로 날아 들어갈 수도 있습니다.
시작 화면에서 끌 수 있습니다.

**비와 눈** — 날씨는 맑음 5~20분 → 궂은 날 1~5분으로 저절로 오갑니다.
**R** 키로 자동 → 맑음 → 비 → 눈 → 천둥번개를 직접 고를 수도 있습니다.

- **그 자리의 기온이 무엇이 내릴지 정합니다.** 추운 곳이면 눈, 그 밖에는 비.
  **사막에는 비가 오지 않습니다** (원작과 동일).
- 입자 1,100개의 위치는 전부 **정점 셰이더가 시간으로 계산**합니다. 버퍼는 한 번만 만들고
  CPU는 매 프레임 아무 일도 하지 않습니다. 플레이어를 따라오되 블록 단위로 붙어 있어
  움직여도 빗줄기가 미끄러지지 않습니다.
- **비**는 세로로 길게 늘인 빗줄기, **눈**은 좌우로 하늘거리는 동그란 송이입니다.
- 궂은 날에는 하늘과 구름이 잿빛이 되고, 햇빛이 30% 어두워지고, 안개가 짙어지고,
  화면 채도가 떨어지고, 햇살(갓레이)이 사라집니다. **천둥번개**는 화면 전체가 번쩍인 뒤
  잠시 있다가 우르릉 소리가 납니다.
- 머리 위가 막혀 있으면(동굴·실내) 입자가 보이지 않습니다.
- 빗소리는 하얀 잡음을 밴드패스로 걸러 한 번만 만들고 크기만 조절합니다.

**쌓이는 눈** — 추운 곳에서는 **하늘에 닿은 것이면 무엇이든** 하얗게 덮입니다.
청크를 장식하고 마을을 세운 **다음에** 기둥마다 맨 위 블록을 찾아 눈을 얹기 때문에,
땅뿐 아니라 **나뭇잎·집 지붕·울타리 위에도 눈이 쌓입니다.** 수면은 얼음이 됩니다
(추운 바다는 통째로 얼어붙습니다).
눈이 내리는 동안에는 플레이어 주변에 눈이 계속 새로 쌓이고, 비가 오면 쌓인 눈이 녹습니다.

### 성층권 — 별과 오로라

구름(높이 84) 위로 올라가면 하늘이 검푸르게 깊어지고 **낮에도 별이 보입니다**.
그리고 **오로라**가 켜집니다 — 세 겹의 커튼이 서로 다른 속도로 물결치고,
방향에 따라 초록과 보라를 오갑니다. 밤일수록 진해집니다.
전부 하늘 셰이더 안에서 계산하므로 추가 비용이 거의 없습니다.

### 몬스터

**몬스터는 나오지 않습니다.** 좀비·스켈레톤·크리퍼·거미는 자연 생성되지 않고,
이미 있던 개체도 사라집니다 (창작 모드 생성 알로는 여전히 불러올 수 있습니다).
밤에도 마음 놓고 돌아다니거나 비행할 수 있습니다.

### 화면 셰이더 (후처리)

장면을 화면에 바로 그리지 않고 **텍스처에 한 번 그린 뒤** 여러 단계를 거쳐 내보냅니다.
시작 화면의 **화면 셰이더** 항목이나 게임 중 **P** 키로 4단계를 오갈 수 있습니다.

| 단계 | 하는 일 | 비용 |
| --- | --- | --- |
| 꺼짐 | 후처리 없음 (원래 화면) | 없음 |
| 기본 | 필름 톤 매핑 · 시간대 색 보정 · 비네팅 · 물속 일렁임 | 전체 화면 1패스 |
| 높음 | ＋ **블룸** (밝은 곳 추출 → 절반 해상도 가우시안 흐리기) | ＋3패스 |
| 최고 | ＋ **갓레이** (해 방향 24샘플) · 두 번 흐리기 · 색수차 | ＋샘플 |

- **하늘에 해·달·별이 생겼습니다.** 화면 좌표를 역투영해 픽셀마다 하늘 방향을 구하고,
  그 방향으로 해·달의 원반과 후광, 방향 해시로 만든 별, 지평선 노을을 그립니다.
- **시간대 색 보정** — 낮은 살짝 따뜻하게, 일출·일몰은 주황, 밤은 푸르게. 채도와 노출도 함께 움직입니다.
- **갓레이**는 해가 화면 안(또는 살짝 밖)에 있고 지평선 위일 때만 켜집니다.
- **물속에서는** 화면이 일렁이고 푸르게 어두워지며, 비네팅이 강해집니다.
- WebGL 프레임버퍼를 못 만드는 기기에서는 **조용히 꺼지고** 원래대로 그립니다. (F3에 "미지원" 표시)

### 물리 — 떨어지는 블록과 폭발

- **떨어진 아이템**은 Y축으로 천천히 돌면서 위아래로 떠오릅니다. 개수가 많으면
  16개마다 한 겹씩, 최대 네 겹으로 겹쳐 보입니다 (원작과 동일).
- **모래·자갈·콘크리트 가루**는 아래가 비면 **낙하 엔티티**가 되어 실제로 떨어집니다.
  떨어지는 동안 정육면체로 그려지고, 착지하면 다시 블록이 됩니다. 여러 개가 동시에 떨어지면 위로 쌓입니다.
  머리 위로 떨어지면 아픕니다.
- **TNT**는 **부싯돌과 부시**로 우클릭하면 점화됩니다. 4초 도화선 동안 점점 빠르게 번쩍이며
  튀어 오르고, 터지면 구 모양으로 블록을 부숩니다.
  - 반지름을 무작위로 흔들어 울퉁불퉁한 구덩이가 생깁니다
  - 부순 블록의 30%가 아이템으로 떨어집니다
  - **흑요석과 기반암은 버팁니다**
  - 범위 안의 다른 TNT는 짧은 도화선으로 **연쇄 폭발**합니다
  - 플레이어·몹·아이템이 거리에 따라 날아가고 피해를 입습니다 (화면도 흔들립니다)

### 제작 912가지 + 제련 63가지

- 계단/반블록/벽 레시피는 블록 목록을 훑어 **자동 등록**됩니다.
- 목재 12종 × 판자·막대기·울타리·문·다락문·버튼·압력판·표지판·보트가 각각 따로 있습니다.
- 색상 16종 × 카펫·침대·현수막·콘크리트 가루·테라코타·색유리·양초·셜커 상자, 염료 조합 전부.
- 네더라이트 도구·방어구는 다이아몬드 장비 + 네더라이트 주괴 + 형판으로 업그레이드합니다.
- 재료가 1200종을 넘어가므로 **재료별 역색인**으로 레시피를 찾습니다 (선형 검색 아님).

### 세계

- **바이옴 7종** — 바다, 해변, 평원, 숲, 사막, 산, 설원. 온도·습도 노이즈로 나뉩니다.
- 프랙탈 펄린 노이즈 지형 + 3차원 노이즈 동굴 + 깊이별 광맥. y16 아래는 심층암이라 광석도 심층암 변종이 나옵니다.
- 바이옴마다 다른 나무, 선인장, 사탕수수, 꽃 10종, 버섯이 자랍니다.
- **하늘빛과 블록빛을 따로 계산하는 조명** — 횃불을 놓으면 빛이 15칸까지 번지고,
  블록을 부수면 그 자리로 빛이 다시 흘러듭니다. 부드러운 조명과 앰비언트 오클루전이 들어갑니다.
- **20분 낮밤 주기.** 침대를 우클릭하면 밤을 넘기고 리스폰 지점이 그 자리로 바뀝니다.
- 모래·자갈은 아래가 비면 떨어지고, 잔디는 흙으로 번지며, 작물은 밝은 곳에서 자랍니다.

동물은 낮에 밝은 잔디 위에 무리로 나타나고, 적대 몹은 어두운 곳에 나타나 플레이어를 쫓아옵니다.
언데드는 아침 햇빛을 받으면 불타 죽습니다.

### 플레이어

체력 20(하트 10개) · 허기 20 · 산소 · 방어도, 낙하 피해, 익사, 굶주림, 자연 회복,
아이템 떨어뜨리기/줍기, 죽으면 소지품을 떨어뜨리고 리스폰.
**창작 모드**에서는 체력·허기가 고정되고 비행할 수 있으며, 아이템 목록에서 무엇이든 꺼내 쓸 수 있습니다.

### 저장

60초마다, 그리고 창을 닫을 때 `localStorage`에 자동 저장됩니다.
플레이어가 손댄 청크의 블록과 상태(방향·열림·물 단계 등)만 런랭스 압축해서 저장하므로
용량이 작습니다 (보통 10~40KB). 시작 화면의 **이어하기**로 불러옵니다.

**세계를 파일로 옮기기** — 게임 중 `K`를 누르면 `webcraft-<시드>.json` 파일을 내려받습니다.
시작 화면의 **세계 파일 열기**로 그 파일을 고르면 그대로 이어집니다.
PC에서 하던 세계를 휴대폰으로 옮기거나, 백업해 두거나, 저장소가 막힌 웹뷰에서 쓸 때 유용합니다.

저장소를 쓸 수 없는 환경(예: `setDomStorageEnabled(false)` 인 안드로이드 WebView)에서는
시작할 때 안내가 뜨고, `K`로 내보내기만 하면 그대로 계속 즐길 수 있습니다.

### 기술적으로 눈여겨볼 부분

- **청크** 16 × 96 × 16. 블록 id는 16비트(795종), 상태는 별도 1바이트(방향·절반·열림).
  지형 생성 → 장식 → 조명 → 메시 생성 순서로, 프레임마다 **시간 예산(기본 7ms)** 만큼만
  처리해 느린 기기에서도 화면이 끊기지 않습니다.
- **상자 모델 메시** — 블록마다 상자 목록을 갖고, 각 상자 면의 UV를 상자가 블록 안에서
  차지하는 위치에 맞춰 잘라 씁니다(그래서 반블록 옆면이 텍스처 아래쪽 절반만 보입니다).
  블록 경계에 걸친 면만 이웃과 컬링하고, 안쪽 면은 항상 그립니다.
- **아이콘 스프라이트 시트** — 1239장을 한 장의 캔버스에 모아 DOM은 `background-position`으로,
  WebGL은 같은 이미지를 2의 거듭제곱 크기로 축소해 씁니다 (WebGL 1의 밉맵 제약).
- **나무가 청크 경계에서 잘리지 않도록**, 각 청크는 이웃 3×3 청크의 장식 목록을
  같은 시드로 다시 계산해서 자기 범위에 걸치는 부분만 기록합니다.
- **조명**은 청크 경계를 넘나드는 BFS로 전파합니다. 블록을 부수거나 놓으면
  기존 빛을 되돌린 뒤(unpropagate) 다시 채웁니다.
- **면 컬링 + 부드러운 조명 + AO**를 메시 생성 때 정점에 구워 넣어 셰이더를 가볍게 유지합니다.
- 불투명 청크는 **앞→뒤**로, 물은 **뒤→앞**으로 정렬해 그립니다.
- 몹과 떨어진 아이템은 매 프레임 하나의 동적 버퍼로 합쳐 **드로우콜 2번**에 그립니다.
- **떨어진 아이템은 입체**입니다. 블록은 6면에 제 텍스처를 붙인 정육면체로,
  도구·재료는 32×32 아이콘의 알파를 16×16 마스크로 읽어 테두리마다 옆면을 세운
  두께 1.5/16짜리 판으로 만듭니다. 이어진 테두리는 한 장으로 합치고(런 병합),
  아이템 종류별로 한 번만 계산해 캐시합니다. 22칸 밖은 앞뒤 두 장짜리 간이 판으로
  낮추고, 한 프레임 정점 예산을 두어 아이템이 아무리 많아도 프레임이 무너지지 않습니다.

## 원본과 다른 점

되도록 원본에 맞췄지만, 웹 한 파일로 만들면서 다음은 다르게 했습니다.

- **레드스톤 회로가 없습니다.** 레드스톤은 재료와 블록으로만 존재합니다.
- **네더·엔드 차원이 없습니다.** 네더랙·발광석 등은 창작 모드 아이템으로만 있습니다.
- **레드스톤 회로가 작동하지 않습니다.** 부품은 모두 있지만 신호는 흐르지 않고 장식으로만 쓰입니다.
  같은 이유로 피스톤·발사기·관측기도 움직이지 않습니다.
- **물약·마법 부여·양조는 아이템과 블록만 있고 효과는 없습니다.** 물약 53종을 들 수는 있지만
  마시면 아무 일도 일어나지 않습니다.
- **네더·엔드 차원이 없습니다.** 네더랙·엔드 스톤 등은 창작 모드와 제작으로만 얻습니다.
- **몹은 8종**입니다. 생성 알 78종은 목록에 있지만 실제로 소환되지는 않습니다.
- **표지판·현수막·지도에 내용을 쓸 수 없습니다.** 블록으로 놓이기만 합니다.
- **활·쇠뇌·삼차창을 쏠 수 없습니다.** 근접 공격만 동작합니다.
- **쿠키**는 원본 레시피(코코아콩)와 설탕 대체 레시피를 둘 다 넣었습니다.
- **불이 번지지 않습니다.** 부싯돌과 부시는 TNT 점화에만 쓰입니다.
- **소리**는 캐기·놓기·쉿·폭발 네 가지 효과음만 코드로 합성해 냅니다.

## 내용 추가하기

**블록 추가** — `blockfamilies.js`에 한 줄이면 아이템·아이콘·창작 모드 목록까지 자동으로 만들어집니다.
텍스처는 `tex(이름, {kind: ...})`로 요청하면 `textures.js`의 생성기가 그려 줍니다.

```js
// blockfamilies.js — 단독 블록
defBlock('my_block', '내 블록', {
  tex: { all: tex('my_block', { kind: 'speck', color: '#8844cc', spot: '#ffffff' }) },
  hardness: 3, tool: TOOL_PICKAXE, tier: 2, light: 7, group: 'building'
});

// 계단·반블록·벽까지 한 번에
defStoneFamily('my_stone', '내 돌', { kind: 'noise', color: '#8844cc', amt: 12 },
  { hardness: 2, variants: ['stairs', 'slab', 'wall'] });
```

새 모양이 필요하면 `blocks.js`의 `SHAPES`에 상자 목록을 추가하고 `render: RENDER_BOXES, boxes: SHAPES.내모양`
으로 지정하면 렌더링·충돌·선택 상자가 모두 그 모양을 따릅니다.

**레시피 추가** — `crafting.js`에 한 줄.

```js
shaped(['DDD', 'DSD', 'DDD'], { D: 'diamond', S: 'stick' }, 'my_block', 1);
shapeless(['coal', 'stick'], 'torch', 4);
smelt('my_block', 'diamond');
```

고친 뒤 `node build.js`로 단일 파일을 다시 만들면 됩니다.

## 동작 환경

WebGL 1.0을 지원하는 브라우저면 됩니다. 안드로이드 WebView(Chrome 기반), iOS WKWebView,
데스크톱 Chrome·Edge·Firefox·Safari에서 동작합니다.
`OES_element_index_uint` 확장이 있으면 자동으로 32비트 인덱스를 써 큰 청크도 한 번에 그립니다.

시작 화면에서 **렌더 거리**를 3~12 사이로 조절할 수 있습니다. 기기가 버거우면 낮추세요.
