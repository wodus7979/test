# WebCraft — 웹뷰에서 도는 마인크래프트

자바 마인크래프트를 참고해 **처음부터 직접 만든 복셀 게임**입니다.
게임 엔진, 지형 생성, 조명, 렌더러, 텍스처, 아이템 아이콘까지 전부 이 저장소 안의 코드로 만들어졌습니다.

- **외부 라이브러리 0개** — Three.js도, 번들러도, npm 패키지도 쓰지 않습니다. 순수 WebGL 1.0 + 바닐라 JS.
- **외부 이미지 0개** — 블록 텍스처와 아이템 아이콘을 실행할 때 픽셀 단위로 그립니다.
- **네트워크 0회** — 파일 하나만 있으면 비행기 모드에서도 돌아갑니다. 웹뷰에 그대로 넣으면 됩니다.

---

## 실행 방법

### 1. PC에 파일로 설치 (가장 편한 방법)

`dist/minecraft.html` **파일 하나만** 있으면 됩니다. 원하는 폴더에 두고 **더블클릭**하면 끝입니다.
설치 프로그램도, 인터넷도, 다른 파일도 필요 없습니다.

바탕화면에 바로가기를 만들어 두면 게임처럼 쓸 수 있습니다.

| 운영체제 | 방법 |
| --- | --- |
| 윈도우 | `minecraft.html` 우클릭 → **보내기 → 바탕 화면(바로 가기 만들기)** |
| 맥 | `minecraft.html` 우클릭 → **별칭 만들기** 후 원하는 곳으로 옮기기 |
| 리눅스 | 파일 관리자에서 링크 만들기 |

저장소를 함께 받았다면 `run/` 폴더의 실행 파일을 더블클릭해도 됩니다.

```
run/윈도우에서-실행.bat        윈도우
run/맥에서-실행.command        맥 (처음 한 번 chmod +x 필요할 수 있음)
run/리눅스에서-실행.sh         리눅스
```

**전체 화면으로 하고 싶으면** 브라우저에서 `F11`(맥은 `Ctrl+Cmd+F`)을 누르세요.

### 2. 웹뷰에 넣기

같은 파일 하나를 그대로 넣으면 됩니다.

```java
// 안드로이드 WebView 예시
webView.getSettings().setJavaScriptEnabled(true);
webView.getSettings().setDomStorageEnabled(true);   // ← 이걸 켜야 자동 저장이 됩니다
webView.loadUrl("file:///android_asset/minecraft.html");
```

```swift
// iOS WKWebView 예시
let url = Bundle.main.url(forResource: "minecraft", withExtension: "html")!
webView.loadFileURL(url, allowingReadAccessTo: url.deletingLastPathComponent())
```

### 3. 원본 소스로 실행

`web/index.html`을 브라우저에서 열면 됩니다. 파일을 직접 열어도 동작하지만,
로컬 서버로 여는 편이 더 안전합니다.

```bash
cd web
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

### 4. 소스를 고친 뒤 단일 파일 다시 만들기

```bash
node build.js      # web/ 의 CSS·JS를 전부 인라인해서 dist/minecraft.html 생성
```

### 블록 모양 (정육면체가 아닌 블록)

렌더러가 **상자 목록 모델**을 지원해서 다음이 실제 모양대로 놓이고, 그 모양대로 충돌합니다.

- **계단** — 설치할 때 보는 방향으로 회전, 아랫면을 클릭하면 뒤집힌 계단
- **반블록** — 아래/위 절반, 위에 올라서면 딱 0.5칸만 올라감
- **울타리 · 벽 · 유리판 · 철창** — 이웃과 자동으로 이어짐
- **문 · 다락문 · 울타리문** — 우클릭으로 여닫기 (문은 위아래 두 칸이 함께 움직임)
- **카펫 · 압력판 · 버튼 · 눈층 · 레일** — 밟고 지나갈 수 있는 얇은 판
- **횃불 · 양초 · 랜턴 · 사슬 · 엔드 막대 · 사다리 · 화분 · 케이크 · 모루 · 가마솥 · 깔때기 · 침대**

색유리·얼음·슬라임·꿀 블록은 알파 블렌딩 패스로 그려 **뒤가 실제로 비쳐 보입니다.**

### 물리 — 물과 용암이 실제로 흐릅니다

**물 바로 앞 땅을 파면 물이 그 방향으로 흘러나옵니다.** 원본과 같은 방식으로 계산합니다.

- **수원과 흐르는 물** — 수원(단계 0)에서 옆으로 퍼질 때마다 단계가 1 내려가고, 7이 되면 멈춥니다.
  그래서 물은 수원에서 최대 7칸까지 퍼집니다. 단계가 커질수록 수면이 낮아지고, 꼭짓점 높이를
  이웃과 평균해 **수면이 자연스럽게 기울어집니다.**
- **낭떠러지를 찾아 흐릅니다** — 옆으로 퍼질 때 5칸 안에서 아래로 떨어질 수 있는 곳까지의
  최단 경로를 너비 우선 탐색으로 찾아, 그 방향으로 먼저 흘러갑니다. 평지에서는 사방으로 퍼집니다.
- **떨어지는 물** — 아래가 비면 먼저 떨어지고, 떨어지는 물은 바닥에서 다시 수원처럼 퍼집니다.
- **저절로 마릅니다** — 수원을 없애면 단계가 하나씩 올라가며 흐르던 물이 전부 사라집니다.
- **무한 물** — 수원 2개가 붙어 있으면 사이의 흐르는 물이 새 수원이 됩니다.
- **물살이 밀어냅니다** — 흐르는 방향으로 플레이어가 밀립니다.
- **씻겨 나갑니다** — 물이 지나가면 풀·꽃·횃불·카펫·레일이 아이템으로 떨어집니다.
- **용암** — 단계가 2씩 내려가 3칸만 퍼지고, 물보다 6배 느리게(30틱) 흐릅니다.
  물에 닿으면 수원은 **흑요석**, 흐르는 용암은 **조약돌**로 굳습니다. 안에 들어가면 아주 느려지고 아픕니다.
- **콘크리트 가루**가 물에 닿으면 콘크리트로 굳습니다.

계산은 원본처럼 **예약 갱신 방식**입니다. 블록이 바뀐 자리 주변만 큐에 넣고, 물은 5틱·용암은 30틱
뒤에 다시 계산합니다. 한 틱에 처리할 개수를 제한해서 큰 호수를 터뜨려도 프레임이 끊기지 않습니다.

### 물리 — 떨어지는 블록과 폭발

- **모래·자갈·콘크리트 가루**는 아래가 비면 **낙하 엔티티**가 되어 실제로 떨어집니다.
  떨어지는 동안 정육면체로 그려지고, 착지하면 다시 블록이 됩니다. 여러 개가 동시에 떨어지면 위로 쌓입니다.
  머리 위로 떨어지면 아픕니다.
- **TNT**는 **부싯돌과 부시**로 우클릭하면 점화됩니다. 4초 도화선 동안 점점 빠르게 번쩍이며
  튀어 오르고, 터지면 구 모양으로 블록을 부숩니다.
  - 반지름을 무작위로 흔들어 울퉁불퉁한 구덩이가 생깁니다
  - 부순 블록의 30%가 아이템으로 떨어집니다
  - **흑요석과 기반암은 버팁니다**
  - 범위 안의 다른 TNT는 짧은 도화선으로 **연쇄 폭발**합니다
  - 플레이어·몹·아이템이 거리에 따라 날아가고 피해를 입습니다 (화면도 흔들립니다)

- 재료가 1200종을 넘어가므로 **재료별 역색인**으로 레시피를 찾습니다 (선형 검색 아님).

### 세계

- **바이옴 7종** — 바다, 해변, 평원, 숲, 사막, 산, 설원. 온도·습도 노이즈로 나뉩니다.
- 프랙탈 펄린 노이즈 지형 + 3차원 노이즈 동굴 + 깊이별 광맥. y16 아래는 심층암이라 광석도 심층암 변종이 나옵니다.
- 바이옴마다 다른 나무, 선인장, 사탕수수, 꽃 10종, 버섯이 자랍니다.
- **하늘빛과 블록빛을 따로 계산하는 조명** — 횃불을 놓으면 빛이 15칸까지 번지고,
  블록을 부수면 그 자리로 빛이 다시 흘러듭니다. 부드러운 조명과 앰비언트 오클루전이 들어갑니다.
- **20분 낮밤 주기.** 침대를 우클릭하면 밤을 넘기고 리스폰 지점이 그 자리로 바뀝니다.
- 모래·자갈은 아래가 비면 떨어지고, 잔디는 흙으로 번지며, 작물은 밝은 곳에서 자랍니다.

### 몹 8종

| 몹 | 성질 | 드랍 |
| --- | --- | --- |
| 돼지 | 온순 | 생 돼지고기 |
| 소 | 온순 | 생 소고기, 가죽 |
| 양 | 온순 | 생 양고기, 하양 양털 |
| 닭 | 온순 | 생 닭고기, 깃털 |
| 좀비 | 적대 | 썩은 살점 |
| 스켈레톤 | 적대 | 뼈, 화살 |
| 크리퍼 | 적대 | 화약 |
| 거미 | 적대 | 실, 거미 눈 |

동물은 낮에 밝은 잔디 위에 무리로 나타나고, 적대 몹은 어두운 곳에 나타나 플레이어를 쫓아옵니다.
언데드는 아침 햇빛을 받으면 불타 죽습니다.

### 플레이어

체력 20(하트 10개) · 허기 20 · 산소 · 방어도, 낙하 피해, 익사, 굶주림, 자연 회복,
아이템 떨어뜨리기/줍기, 죽으면 소지품을 떨어뜨리고 리스폰.
**창작 모드**에서는 체력·허기가 고정되고 비행할 수 있으며, 아이템 목록에서 무엇이든 꺼내 쓸 수 있습니다.

### 저장

60초마다, 그리고 창을 닫을 때 `localStorage`에 자동 저장됩니다.
플레이어가 손댄 청크의 블록과 상태(방향·열림·물 단계 등)만 런랭스 압축해서 저장하므로
용량이 작습니다 (보통 10~40KB). 시작 화면의 **이어하기**로 불러옵니다.

**세계를 파일로 옮기기** — 게임 중 `K`를 누르면 `webcraft-<시드>.json` 파일을 내려받습니다.
시작 화면의 **세계 파일 열기**로 그 파일을 고르면 그대로 이어집니다.
PC에서 하던 세계를 휴대폰으로 옮기거나, 백업해 두거나, 저장소가 막힌 웹뷰에서 쓸 때 유용합니다.

저장소를 쓸 수 없는 환경(예: `setDomStorageEnabled(false)` 인 안드로이드 WebView)에서는
시작할 때 안내가 뜨고, `K`로 내보내기만 하면 그대로 계속 즐길 수 있습니다.

    ├── blockfamilies.js 블록 795종 — 목재 12종·색상 16종·돌 계열을 생성기로 한 번에 만듦

    ├── world.js        청크, 지형 생성, 빛 전파, 메시 생성, 레이캐스트

### 기술적으로 눈여겨볼 부분

- **청크** 16 × 96 × 16. 블록 id는 16비트(795종), 상태는 별도 1바이트(방향·절반·열림).
  지형 생성 → 장식 → 조명 → 메시 생성 순서로, 프레임마다 **시간 예산(기본 7ms)** 만큼만
  처리해 느린 기기에서도 화면이 끊기지 않습니다.
- **상자 모델 메시** — 블록마다 상자 목록을 갖고, 각 상자 면의 UV를 상자가 블록 안에서
  차지하는 위치에 맞춰 잘라 씁니다(그래서 반블록 옆면이 텍스처 아래쪽 절반만 보입니다).
  블록 경계에 걸친 면만 이웃과 컬링하고, 안쪽 면은 항상 그립니다.
- **아이콘 스프라이트 시트** — 1239장을 한 장의 캔버스에 모아 DOM은 `background-position`으로,
  WebGL은 같은 이미지를 2의 거듭제곱 크기로 축소해 씁니다 (WebGL 1의 밉맵 제약).
- **나무가 청크 경계에서 잘리지 않도록**, 각 청크는 이웃 3×3 청크의 장식 목록을
  같은 시드로 다시 계산해서 자기 범위에 걸치는 부분만 기록합니다.
- **조명**은 청크 경계를 넘나드는 BFS로 전파합니다. 블록을 부수거나 놓으면
  기존 빛을 되돌린 뒤(unpropagate) 다시 채웁니다.
- **면 컬링 + 부드러운 조명 + AO**를 메시 생성 때 정점에 구워 넣어 셰이더를 가볍게 유지합니다.
- 불투명 청크는 **앞→뒤**로, 물은 **뒤→앞**으로 정렬해 그립니다.
- 몹과 떨어진 아이템은 매 프레임 하나의 동적 버퍼로 합쳐 **드로우콜 2번**에 그립니다.

## 원본과 다른 점

되도록 원본에 맞췄지만, 웹 한 파일로 만들면서 다음은 다르게 했습니다.

- **레드스톤 회로가 없습니다.** 레드스톤은 재료와 블록으로만 존재합니다.
- **네더·엔드 차원이 없습니다.** 네더랙·발광석 등은 창작 모드 아이템으로만 있습니다.
- **레드스톤 회로가 작동하지 않습니다.** 부품은 모두 있지만 신호는 흐르지 않고 장식으로만 쓰입니다.
  같은 이유로 피스톤·발사기·관측기도 움직이지 않습니다.
- **물약·마법 부여·양조는 아이템과 블록만 있고 효과는 없습니다.** 물약 53종을 들 수는 있지만
  마시면 아무 일도 일어나지 않습니다.
- **네더·엔드 차원이 없습니다.** 네더랙·엔드 스톤 등은 창작 모드와 제작으로만 얻습니다.
- **몹은 8종**입니다. 생성 알 78종은 목록에 있지만 실제로 소환되지는 않습니다.
- **표지판·현수막·지도에 내용을 쓸 수 없습니다.** 블록으로 놓이기만 합니다.
- **활·쇠뇌·삼차창을 쏠 수 없습니다.** 근접 공격만 동작합니다.
- **쿠키**는 원본 레시피(코코아콩)와 설탕 대체 레시피를 둘 다 넣었습니다.
- **불이 번지지 않습니다.** 부싯돌과 부시는 TNT 점화에만 쓰입니다.
- **소리**는 캐기·놓기·쉿·폭발 네 가지 효과음만 코드로 합성해 냅니다.

## 내용 추가하기

**블록 추가** — `blockfamilies.js`에 한 줄이면 아이템·아이콘·창작 모드 목록까지 자동으로 만들어집니다.
텍스처는 `tex(이름, {kind: ...})`로 요청하면 `textures.js`의 생성기가 그려 줍니다.

```js
// blockfamilies.js — 단독 블록
defBlock('my_block', '내 블록', {
  tex: { all: tex('my_block', { kind: 'speck', color: '#8844cc', spot: '#ffffff' }) },
  hardness: 3, tool: TOOL_PICKAXE, tier: 2, light: 7, group: 'building'
});

// 계단·반블록·벽까지 한 번에
defStoneFamily('my_stone', '내 돌', { kind: 'noise', color: '#8844cc', amt: 12 },
  { hardness: 2, variants: ['stairs', 'slab', 'wall'] });
```

새 모양이 필요하면 `blocks.js`의 `SHAPES`에 상자 목록을 추가하고 `render: RENDER_BOXES, boxes: SHAPES.내모양`
으로 지정하면 렌더링·충돌·선택 상자가 모두 그 모양을 따릅니다.

**레시피 추가** — `crafting.js`에 한 줄.

```js
shaped(['DDD', 'DSD', 'DDD'], { D: 'diamond', S: 'stick' }, 'my_block', 1);
shapeless(['coal', 'stick'], 'torch', 4);
smelt('my_block', 'diamond');
```

고친 뒤 `node build.js`로 단일 파일을 다시 만들면 됩니다.

## 동작 환경

WebGL 1.0을 지원하는 브라우저면 됩니다. 안드로이드 WebView(Chrome 기반), iOS WKWebView,
데스크톱 Chrome·Edge·Firefox·Safari에서 동작합니다.
`OES_element_index_uint` 확장이 있으면 자동으로 32비트 인덱스를 써 큰 청크도 한 번에 그립니다.

시작 화면에서 **렌더 거리**를 3~12 사이로 조절할 수 있습니다. 기기가 버거우면 낮추세요.
