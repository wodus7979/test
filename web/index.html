조작법 / 게임 안내

PC

  • WASD 이동 · Space 점프 · Shift 웅크리기 · Ctrl 달리기
  • 마우스 시점 · 좌클릭 캐기/공격 · 우클릭 설치/사용/먹기
  • 1~9 또는 휠 핫바 선택 · Q 버리기 (Ctrl+Q 전부)
  • E 인벤토리 · G 창작/생존 전환 · C 전체 아이템 목록(창작)
  • F 또는 Space 두 번 비행 켜기/끄기 (창작 모드) · 비행 중 Space 상승, Shift 하강
  • F3 디버그 정보 · O 즉시 저장 (60초마다 자동 저장) · P 화면 셰이더 바꾸기
  • R 날씨 바꾸기 (자동 → 맑음 → 비 → 눈 → 천둥번개). 추운 지방에서는 비 대신 눈이 온다
  • M 지도 배율 바꾸기 · N 목적지 공항 바꾸기
  • 주민에게 우클릭하면 거래창이 열린다 (에메랄드가 마을의 돈)
  • 비행기에 우클릭하면 탑승 — W/S 추력, 마우스 조종, A/D 방향, Space 제동, Shift 내리기(공중이면 낙하산)
  • 공항은 세 곳(ICN · GMP · CJU)이고 아주 멀다. 계기판의 관제탑 신호를 따라가면 된다
  • 목적지까지 500블록이 남으면 자동 착륙 승인 창이 뜬다 — Y 승인, N 취소
  • 도시 길에는 자동차 여덟 종류(승용차·택시·승합차·버스·트럭·순찰차·소방차)가 우측통행으로 달리고, 교차로에서 방향을 튼다. 앞에 서 있으면 멈춘다. 도시마다 경찰서와 소방서도 있다
  • 공항마다 도시가 하나씩 딸려 있고 생김새가 저마다 다르다 — 유리 신도시 인천 송도, 롯데타워와 벽돌 상가 거리가 섞인 김포 도심, 현무암 기단에 주황 기와를 얹은 제주시. 횡단보도와 가로수도 있다. 지도에 네모로 표시된다
  • 터미널 옆 공항철도역에서 3량짜리 전동차가 도시까지 오간다. 바퀴가 실제로 구르고, 객실 안을 걸어 다닐 수 있다 — 열차에 우클릭하면 타고, 안에서 WASD로 움직이고, Shift로 내린다
  • 공항 안은 의자·소파·카운터·진열장 같은 진짜 가구로 꾸며져 있다 (창작 모드 가구 탭)
  • 구름 위로 올라가면 비·눈이 미치지 않고, 별과 오로라가 보인다. 하늘이 두 배로 높아져 고도 150까지 올라갈 수 있다
  • K 세계를 파일로 내보내기 — 다른 PC·휴대폰으로 옮기거나 백업할 때

모바일 / 웹뷰

  • 화면 왼쪽을 끌면 조이스틱, 오른쪽을 끌면 시점 이동
  • 오른쪽 짧게 탭 = 설치/사용, 길게 누르기 = 캐기
  • 오른쪽 아래 버튼으로 점프·웅크리기·가방

진행 순서 (원본과 동일)

  • 나무를 캐서 판자 → 막대기 → 제작대를 만든다
  • 나무 곡괭이로 돌을 캐고 돌 도구와 화로를 만든다
  • 석탄으로 횃불을 만들어 동굴을 탐험하고 철·금·다이아몬드를 캔다
  • 밤에는 좀비와 스켈레톤이 나온다. 집을 짓고 문 대신 블록으로 막자
